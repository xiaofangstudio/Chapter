## 一 定位

一句话：**给写长篇小说的人用的写作工作台——章节、场景、人物设定、字数目标，全在一处，写完直接导出 EPUB。**

和家族里另外两个文字产品分工清楚：

| 产品 | 管什么 |
| --- | --- |
| **Chit** | 纯文本，秒开，记事 |
| **Scheda** | Markdown，带图带目录 |
| **Chapter** | 长篇小说：章节结构、场景卡片、人物设定、字数压力、成书导出 |

不做的：不写 Markdown 渲染器（那是 Scheda），不做通用文档排版（那是 Penna/Foliox），不联网、不上传、不自带模型——AI 只通过本机 MCP 服务由你自己接的客户端调用，版本管理也只用本机 Git，不碰云端。

## 二 一期范围（目标：快速出可用版本）

只做能让自己立刻开始写书的最小闭环，八件事：

1. **书架**：新建书、打开、最近打开、重命名、删除
2. **章节树**：卷 → 章 → 场景 三级，拖拽排序、折叠
3. **正文编辑**：标题、加粗、斜体、引用、分隔线；粘贴保留段落；撤销重做
4. **字数**：本章 / 全书 / 今日新增，每日目标与总目标进度条
5. **专注模式**：隐藏所有面板，只剩正文，打字机滚动（光标始终居中）
6. **大纲卡片**：把章节拉成卡片墙，写摘要、拖动调序
7. **人物与设定表**：人物、地点、物品三类，字段自定义（姓名/身份/外貌/备注），正文里可插入引用
8. **导出**：TXT、Markdown、EPUB 3（带目录、章节分页、封面）

配套：自动保存（停手 1.4 秒 + 30 秒兜底 + 失焦/切页/关窗强制存盘）、本地快照（每次打开生成一个版本，可回滚最近 20 个）。

## 二·五 v1.1 新增

- **书稿导入**：TXT / Markdown / DOCX。TXT 自动按 UTF-8 读取，失败回退 GB18030；DOCX 直接解包读取正文，不依赖 Word。
- **自动分章**：识别 `# 标题`、`第X章 / 回 / 节`、`第X卷 / 部`、`Chapter N`、`Volume N`、序章 / 楔子 / 尾声 / 番外；识别结果可继续手动修正。
- **可视化手动分章**：全屏导入工作台。左侧原文可框选，选中一行标题按 `Enter` 即切成下一章；行内可切「章 / 卷」、删除切点、撤销、重新识别、清空；最后一个「完成导入」收尾。关闭窗口自动保存，支持 `Ctrl+S / Z / A / C / V / X`。
- **卷 → 章 → 正文**：章节大纲墙可直接「新建一卷」，卷下挂章；导入时 `第X卷` 自动归卷。
- **整书大纲**：与章节大纲分开，属于整本书，换章不丢。左侧可视化积木栏（一级 / 二级标题、加粗、引用、清单、分隔线、三幕骨架）直接往 Markdown 里插符号，不会 Markdown 也能写。
- **工作台模式**：番茄作家专区风格的离线仪表盘——作品 / 累计 / 今日 / 连续天数、正在连载、打卡日历、今日目标环、最近 7 天柱、最近作品。与「极简模式」在设置里随时互换。
- **六十余种界面语言**：简体中文、繁體中文、English、日本語、한국어、Français、Deutsch、Español、Português、Русский、العربية 等 65 种可选，选择器带搜索；阿拉伯语、乌尔都语、希伯来语、维吾尔语整界面 RTL 镜像。
- **纸面质感**：素纸 / 细纹 / 宣纸 / 横线 / 点阵；暗色模式下纸仍是纸色。背景图只铺界面底层，正文保持干净白纸。
- **卡片边缘流光**：鼠标靠近任意卡片，纯白带一点暖 / 冷色散的光沿外圈缓慢流动，只作用卡片边框，不照文字。
- **细节**：视图入场、按钮按压、保存点脉冲、章节超长自动换行与滚动条稳定占位；章节字数无上限。
- **修复**：右上角「⋯」菜单点击无反应（改为 portal + fixed 层级）；关闭窗口不退出（补窗口 close/destroy 权限并兜底 destroy）。

## 二·六 v1.2 新增

- **小说介绍页**：从书架点开一本书，先进入作品介绍，而不是直接跳进编辑器。介绍页展示封面、书名、笔名、上次更新时间、简介，以及字数、章数、卷数和目标进度。
- **卷目录手风琴**：介绍页下方按卷排列目录，展开一卷只露出这一卷的章节，其他卷被顶下去或收起；再点同一卷可全部收起。每章显示全局序号、标题、摘要和字数，当前章高亮。
- **明确的进入与返回路径**：点章节进入写作页；在写作页点其他章节仍留在写作页；只有再次点「当前已选中的章节」才回到介绍页。整条链路尽量保留同一套入场与折叠动画。
- **书籍设置**：介绍页可直接改书名、笔名和小说简介。保存后同步刷新书架卡片、顶栏书名与介绍页，简介只用于介绍页，不进入正文。
- **封面入口**：介绍页封面悬停出现「更换封面」，点击沿用原有封面选择与存储逻辑。

## 二·七 v1.2.1 新增

- **背景统一**：书架、介绍页、写作页共用同一层 `AmbientBackdrop`，不再给介绍页单独画一张黄底。它只挂载一次，切换场景时由同一批节点位移、缩放，不会重新加载第二份素材。
- **金色丝线**：在登录页原有的暖光与纸纹上，加入四道极细的金色曲线。曲线几何只定义一次，光晕与芯线复用同一组路径；慢速呼吸与场景位移让它像流动的丝，而不是硬金条。
- **透景写作页**：写作页中央舞台保留一层薄背景，金色丝线会在纸页边缘和空处隐约露出，进入编辑器时与介绍页保持同一张背景。

- **设置中心重做**：换成一块大磨砂玻璃面板，左侧五个栏目（个性化 / 写作与纸面 / AI 与 MCP / 版本与回档 / 关于 Chapter），右侧只显示当前栏目的单页内容，不再是一根滚到底的长条。

- **封面全站同源**：新增唯一的封面组件 `NovelCover`。工作台、极简书架、书籍介绍页左上角、顶栏书标、3D 书正面全部渲染同一套素材与排版，不再一处一个样。

- **i18n 拆分**：文案按 common / manual / more / notes / stats / world 分模块维护，主包不再是一个巨无霸文件。
- **圆角统一**：封面、卡片、按钮、弹窗全部回到同一套 radius 令牌，不再出现 7px / 9px / 13px 混用。

## 二·十一 v1.4.0 新增

- **分光重做**：跟着鼠标走的暖光 + 冷色棱镜散光改成独立顶层软光层，不再被卡片和版心吃掉；浅色是低透明度暖 / 冷双色晕，暗色自动切滤色模式。亮机本（≤4 核或 ≤4GB 内存）自动降为静态低透明度，不跑逐帧描边和近距卡片扫描。

- **自打印工作台**：导出多一张「自打印」格式卡，选 PDF 或 Word 后进入全屏排版页。纸张 A4 / A5 / B5 / 16K、三档页边距、宋体 / 黑体、9–16pt 字号、1.4–2.2 行距、首行缩进、每章分页、带不带副文本、章节插图、当前章 / 全书预览与缩放都能调。PDF 走 Edge 无头真实打印；Word 由 Rust 手写 OOXML 生成可继续编辑的 `.docx`，分页、字体、行距、首行缩进和插图都保留。

- **灵感便签变 Obsidian 式**：左栏新建 / 搜索 / 置顶 / 标签 chip 的笔记列表，右栏标题、置顶、Markdown 编辑与实时预览双栏、字符与标签统计，500ms 防抖自动存本地。
- **写作页字号**：工具栏加 `A− / 数字 / A+`，14–24px 可调，按书本地记住，正文与纸面同步缩放。
- **导入不凭空造章**：书名 / 作者 / 来源 / 短标题这类抬头不会再被切成「前言」，空章直接跳过，只有全文都空才回退一章「全文」。

- **故事地图**：大纲页新增按卷铺开的章节画布，卡片可以自由拖动摆位，位置只存在这台电脑（`chapter.storymap:<书 id>`），用来理清故事线。
- **关系图**：人物 / 地点 / 设定等条目多了图谱视图，节点可拖动、可拉关系并给关系起名（如「师徒」「宿敌」），关系随 `book.json` 一起保存。
- **正文字体可换**：设置里可上传本地字体文件，只影响写作区、不改导出排版；字体数据只读一次并缓存，切章不再几十兆地反复编码，文件丢失会自动回退宋体。
- **书脊取自封面**：自定义封面自动裁左侧一竖列做书脊并保留竖排书名，不再需要单独挑书脊颜色。
- **世界观视图**：顶栏新增「世界观」入口，设定在卡片 / 关系图 / 世界地图三种视图间切换。
- **大纲板**：章节大纲改成卷 / 章卡片，拖右侧把手排序，就地新建卷与章，一章一句梗概，场景列表跟着走。
- **自打印补齐成品结构**：三套排版预设（成书 A5 / 投稿 A4 / 打印店 A4），可加前置空白页、书名页、自动目录与每章页码、正文页脚页码、尾部空白页；目录页码先按版心估算、导出时后端再精确重排。
- **滚动位置记忆**：去大纲看两眼再回来，正文还停在刚才那一行（存 sessionStorage，关掉软件即清）。
- **四种新语言**：藏语、维吾尔语（RTL）、蒙古语、壮语，语言总数到 65。
- **漫画工作台**：新建书可选「漫画」，页面轨、分格画布、格内聚焦、画笔 / 橡皮 / 气泡 / 图片、保存重开都在同一套书壳里；漫画工程落在 `书名.chapter/comic/pages/`。
- **分格外圈贴纸边**：模板分「连环画 / 漫画 / 整页」三组。连环画有六格、四格、九宫格、八格、电影条、大场面、三连、四横条、三竖格、主格五连；漫画有切角四格、斜切三格、放射五格、错位四格。所有模板最外圈格的上边水平、下边水平、左边垂直、右边垂直，只有内侧分割线可以斜切；不再额外套一圈装饰页框。
- **填充与吸色**：格内聚焦新增「填充」「吸色」。填充只铺与落点相近的连通区，抗锯齿边缘留线稿；吸色点画稿任意不透明像素，取到后直接切回画笔。
- **正文段落**：自然段之间固定空 0.7 行，段首默认缩进两个字；改字号或行高后仍然按 0.7 行算。
- **极简模式也有手机互传**：首页右上角直接进局域网互传，不必先切到工作台模式。
- **自己画格**：工具栏「手绘格」或模板弹窗「手绘一格」进入点四角模式，前三步有橙色虚线预览，第四角落下生成四边形；四点自交或面积太小会拒绝。
- **四边形可改形**：选中斜切格后是四个真实角点手柄，不是包围盒八方块；拖动任一角，命中、裁剪、气泡落点、格内落笔和保存都跟着新形状走。
- **覆盖不残留**：套模板会同时清格、气泡、图片；页面只有气泡或图片也会先确认；改角 / 缩放撤销后画布同步回滚，重做按新尺寸重新铺图层。
- **体积**：Windows 安装包约 2.68 MiB，仍然本地优先、零账号、MIT。

## 四 技术路线

| 层 | 选型 | 说明 |
| --- | --- | --- |
| 外壳 | Tauri 2 | 与全家一致，系统 WebView2，安装包小 |
| 界面 | React 19 + TypeScript + Vite | 沿用 FangUI / Strata 的设计令牌与排版规范 |
| 编辑器 | 自研 `contenteditable` | 不引第三方富文本依赖；只保留段落、加粗、斜体、引用、分隔线，粘贴强制纯文本，防止带进外部样式 |
| 核心 | Rust（chapter-core） | 工程读写、字数统计、封面、快照、TXT/Markdown/EPUB 导出 |
| 存储 | JSON + Markdown 明文 | 不用数据库。`book.json` / `outline.json` / `lore.json` 加每章一个 `.md`，坏了能用记事本救 |
| 导出 | `zip` crate 手写 EPUB 3 | 不依赖外部工具；`mimetype` 作为首条 Stored 写入，带 `container.xml` / `content.opf` / `nav.xhtml` / `toc.ncx` |
| AI | 本机 MCP 服务 | 只给卷章、封面、大纲、Markdown 的读写；删除与回档强制人工确认 |
| 版本 | 本机 Git | 每本书一个独立仓库，不联网、不上传 |

界面不碰文件系统，一切走 Rust 命令；正文与快照都落在本地工程目录。

**保存策略**：编辑器停手 1.4 秒自动保存，另有 30 秒兜底；失焦、切章、切视图、新建/删除章节、换封面、导出和关闭窗口时都会强制存盘。顶栏用「未保存 / 保存中 / 已保存」明确反馈，保存失败会弹提示，不会假装成功。

## 五 文件格式

工程是一个目录（照 Float 工程包的习惯），后缀 `.chapter`：

```
我的小说.chapter/
  book.json          书名、作者、简介、封面、目标字数、创建时间
  outline.json       卷/章/场景结构、排序、摘要
  chapters/
    <章 id>.md        每章一个文件，带 id / title / updated 元信息头
  lore.json          人物、地点、物品设定（字段完全自定义）
  snapshots/         最近 20 个快照（按时间戳命名）
  assets/            封面与插图
```

- 纯文本可读：正文是受限 Markdown，坏了能用记事本救
- 可备份：整个 `.chapter` 目录拷走即可迁移
- 不锁定：随时能导出成 TXT、Markdown 或 EPUB 3
- 删除不销毁：删书移到书库下的 `.回收站/<书名>-<时间戳>`，删章改名为 `.md.deleted`

## 六 设计规范（与家族统一，写死）

### 6.1 外观基调

延续 Strata 确立的那套：**清亮、扁平、圆角、轻磨砂、动画多但不喧闹**。浅色为默认，深色可切，全部只引用令牌，不写死颜色。

### 6.2 圆角与间距

| 令牌 | 值 | 用在哪 |
| --- | --- | --- |
| `--r-xs` | 6px | 小控件、标签 |
| `--r-sm` | 8px | 按钮、输入框 |
| `--r-md` | 12px | 面板、卡片 |
| `--r-lg` | 16px | 大容器、弹窗 |
| `--r-full` | 999px | 胶囊、头像 |

间距一律 4 的倍数（4 / 8 / 12 / 16 / 24 / 32 / 48 / 64）。字号 12 / 13 / 14 / 16 / 20 / 26 / 34。

### 6.3 磨砂玻璃（真玻璃，不是糊一层）

- 底色三层全带 alpha，`backdrop-filter: blur() saturate() brightness()` 真正透得过去
- 1px 半透明亮边 + 顶部 1px 内高光 + 双层柔和外阴影，撑出厚度
- **噪点**：叠一层极淡的 SVG 噪点纹理（`feTurbulence`），让玻璃有磨砂颗粒感，而不是塑料膜
- 玻璃卡本体不加会切断采样的 `clip-path`
- 四个参数（透明度 / 磨砂 / 饱和 / 光泽）进偏好设置，所见即所得

只用在悬浮层：弹窗、浮层、工具条、欢迎页卡片。正文编辑区永远是实底白纸——写字的地方不能花。

### 6.4 动效

- 三档：完整 / 精简 / 关，跟随系统「减少动效」分级降级
- 缓动：`--ease-out` 主用，`--ease-spring` 只给弹入
- 时长：120 / 180 / 280 ms
- 必做动效：启动页淡出、欢迎页卡片浮入、章节树展开收起、面板滑入、弹窗进出、字数条增长、专注模式过渡
- 原则：动画服务于「动作有反馈」，不做无意义的背景动画

### 6.5 启动页与欢迎页

**启动页**：深色或浅色底 + 居中 Logo + 一行「Chapter」+ 细进度条，读取书架完成后淡出，不超过 800ms（快于 800ms 也要至少显示 400ms，避免闪）。

**欢迎页**：左侧竖排入口（新建书 / 打开 / 最近），右侧最近书籍卡片墙（封面、书名、进度、最后编辑时间），卡片带玻璃质感与浮入动效。空态给三条写作建议与一个「从模板开始」。

### 6.6 深色模式

- 令牌成对：`--bg` / `--surface` / `--text` / `--border` 全部双套
- 强调色在深色下提亮一档，保证对比度
- 正文纸面两套主题都是白纸（写作用户的纸张习惯不反转），只有界面框架反转
- 切换即时生效，无刷新

### 6.7 主题色：夕阳暖黄

浅色主调为**暖黄加磨砂，夕阳感**——底色不是冷白，是带夕阳余温的米白；强调色是落日橙金；玻璃层带暖调，像傍晚隔着薄纱看光。

**浅色（默认）**

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--bg` | `#faf5ec` | 窗口底，暖米白 |
| `--surface` | `#fffdf8` | 卡片、面板 |
| `--surface-2` | `#f5eee2` | 次级面、侧栏 |
| `--border` | `#e8dcc8` | 分隔线 |
| `--text` | `#2b2117` | 正文，暖墨 |
| `--text-2` | `#6b5c4b` | 次要文字 |
| `--text-3` | `#9c8b78` | 提示文字 |
| `--accent` | `#c96a1f` | 主强调，落日橙（白字对比达标） |
| `--accent-hover` | `#b25b16` | 悬停 |
| `--accent-light` | `#f0a34a` | 点缀、进度条、选中态 |
| `--accent-soft` | `rgba(201, 106, 31, 0.12)` | 浅底高亮 |

**深色（夜幕）**——同一色相压暗，强调色提亮：

| 令牌 | 值 |
| --- | --- |
| `--bg` | `#1a1512` |
| `--surface` | `#241d18` |
| `--surface-2` | `#2e2620` |
| `--border` | `#3a3027` |
| `--text` | `#f2e9dd` |
| `--text-2` | `#b3a392` |
| `--accent` | `#f0a34a` |
| `--accent-light` | `#ffc477` |

**夕阳渐变**（只给启动页、欢迎页背景、空态插图用，正文区不用）：

```css
background:
  radial-gradient(120% 90% at 15% 100%, #f6c87a 0%, rgba(246, 200, 122, 0) 55%),
  radial-gradient(100% 80% at 85% 0%, #ffe9c4 0%, rgba(255, 233, 196, 0) 60%),
  #faf5ec;
```

**玻璃层**：暖白 `rgba(255, 250, 242, 0.55)` 打底，`blur(24px) saturate(1.2) brightness(1.04)`，叠极淡噪点；不透明度过低时补一层 `#f2e6d2` 兜底，保证浅色文字始终可读。

约束：全文只有这一味暖橙强调色，不引入第二个彩色；正文纸面保持 `#fffdf8`，不铺渐变。
