## 2. P0-1 文本校对

### 2.1 范围

- **本地运行，不联网**，不上传正文、不上传词库。
- 每本书独立：小说书、漫画书各一份词库，互不影响。
- 漫画书里的气泡对话、旁白、任何文字输入框都走同一套检查。
- 中文为主；英文只做重复空格、全半角、明显拼写重复，不做英文语法。
- 检查结果只是建议，**不自动改正文**；用户点“替换”才改，且进入原有撤销栈。

### 2.2 两类检查

**A. 标点规则**

- 中文句子里出现半角 `, . ? ! : ;` → 建议全角 `，。？！：；`。
- 中文内容使用半角括号/引号 → 建议全角。
- 引号、括号不配对；中文省略号写成 `...`、`。。。` → 建议 `……`。
- 连续重复标点 `！！`、`，，`、`？？` → 建议合并。
- 中文与英文/数字之间缺空格、或多出空格 → 只提示，不强改。
- 句末缺标点 → 只提示，不自动补。

**B. 词语纠错**

- 只检查用户在本节词库里填过的词，不加载巨大的通用词典乱报。
- 典型：词库填「廿七」，正文写「念七」→ 标红，建议「廿七」。
- 词库填「小方」，正文写「小芳」「消防」→ 都标红，建议「小方」。
- 词库填「小芳」时，「小方」同样报错；**以本书填的词为准，不预设谁对**。

### 2.3 拼音判定

每个词条生成两份 key：

1. **无声调 key**：声母 + 韵母，忽略声调。
2. **带声调 key**：声母 + 韵母 + 调号。

扫描同长度文本片段时：

- 无声调 key 相同 → 命中，标淡红。
- 带声调 key 也相同 → 高置信，建议排第一。
- 只有无声调相同、声调不同 → 仍然标红，但置信降一档。
- 声母或韵母不同 → 不命中。

例：

| 词库 | 正文 | 无声调 | 声调 | 结果 |
|---|---|---|---|---|
| 廿七 | 念七 | 完全相同 | 完全相同 | 标红，建议廿七 |
| 小方 | 小芳 | 完全相同 | 完全相同 | 标红，建议小方 |
| 小方 | 消防 | 完全相同 | 不同 | 标红，建议小方 |
| 小方 | 小方 | 相同 | 相同 | 不报，正确 |

### 2.4 防误报

- 默认只检查 **2 字及以上** 的词；单字词容易把「的/得/地」全标红，默认关闭。
- 单字词可手动开启，但只对“声调也完全相同”的异字命中提示。
- 跳过：纯英文单词、URL、代码片段、Markdown 标记、已有批注、正在输入法组合中的文本。
- 同一个位置只保留一条建议；同音多词时最多给 3 个候选。
- 每个词最多记住 300 条/书；到上限后“新增”置灰，提示先删。
- 单章问题最多展示 2000 条；超出停止扫描并提示“先修前面的”，避免整页飘红。
- 忽略某一条后，按“词 + 上下文指纹”记住，不因重新扫描又冒出来。

### 2.5 词库存储

每本书根目录新增 `proofread.json`，与 `book.json / outline.json / lore.json` 同级：

```json
{
  "version": 1,
  "terms": [
    {
      "id": "term_xxx",
      "text": "廿七",
      "enabled": true,
      "note": "猫的名字",
      "createdAt": 0,
      "updatedAt": 0
    }
  ],
  "punctuation": {
    "enabled": true,
    "rules": {
      "halfWidth": true,
      "quotes": true,
      "ellipsis": true,
      "duplicates": true
    }
  },
  "ignored": [
    {
      "termId": "term_xxx",
      "contextHash": "…",
      "span": [12, 14]
    }
  ]
}
```

- 缺文件时按默认配置，旧书不受影响。
- `save_json` 白名单加 `proofread.json`。
- `.chapter` 导出、互传同步包、整库备份都要带上它。
- 不做跨书共享；需要复用时只提供“从另一本书复制词库”的手动入口。

### 2.6 检查与渲染方式

- 输入停顿 400ms 后扫描，不在每次击键时全量扫。
- 优先用 **CSS Custom Highlight API** 给文字加淡红底，不改正文 DOM、不破坏输入法和撤销。
- WebView 不支持 Highlight API 时，回退到临时装饰层；保存前必须剥离，不能写进正文。
- 大章节按段落增量扫描并缓存；只给可视区域附近的问题建装饰。
- 输入法组合期间不扫、不弹；`compositionend` 后再扫。
- 词库修改后只重扫当前章，不重扫全书。

### 2.7 行内样式

- 词语错误：淡红背景 `rgba(255, 92, 92, .14)`，底部 1px 点线，不做整段大红。
- 标点错误：淡琥珀下划线，不铺红底，和词语错误区分。
- 当前被点开的错误加深一点边框；同一时间只允许一个提示浮层。

### 2.8 提示浮层

浮层贴着错误词上方出现；空间不够时翻到下方，左右夹在视口内。

```text
┌─────────────────────────┐
│ 忽略     猜你想写  小方 │
└─────────────────────────┘
```

- 左：`忽略`，中性灰，只忽略当前这一处。
- 右：橙色 `小方`，上方小字 `猜你想写`；点击替换。
- 多候选时橙色候选横向排开，最多 3 个。
- 点击外部、`Esc`、滚动离开视口都收起。
- 替换后光标停在替换词后面，不递归再报，不破坏撤销。

### 2.9 词库弹窗

入口：编辑器工具栏「校对」→「本书词库」；漫画气泡文字编辑框也有「校对」。

**尺寸上限（必须遵守）**

| 端 | 宽度 | 高度 |
|---|---|---|
| 桌面 | `min(720px, 100vw - 64px)` | `min(72vh, 640px)` |
| 手机 | `calc(100vw - 32px)` | `min(76dvh, calc(100dvh - 96px))` |

- 弹窗悬浮在编辑区上方，不再随词条数量无限拉长。
- 头部、底部操作条固定；只有中间列表滚动。
- 列表行高固定，一行一个词；空行也占位，不跳动。
- 手机键盘弹起时，弹窗高度跟着可视高度缩，不顶出屏幕。

**内容**

- 三个 Tab：`词语` / `标点` / `忽略记录`。
- 词语页：`+ 新增` 建一条空白词，输入框自动聚焦；回车保存并再建一条空行。
- 每行：词、拼音预览（如 `niàn qī`）、启用开关、删除。
- 删除二次确认；空白词直接删，不确认。
- 词条多时出现搜索框；搜索不改变排序。
- 底部固定 `保存`；未保存离开给一次提醒。
- 标点页只放各规则开关，不做逐条规则编辑。
- 忽略记录页可“恢复提示”，清空单条或全部。

### 2.10 漫画对话

- 气泡数据仍是 `ComicBalloon.text`，不新增字段。
- 对话编辑框改成能显示高亮的输入层，或“输入框 + 高亮镜像层”。
- 淡红底、浮层、替换与小说编辑器一致。
- 漫画书词库和小说书词库完全独立；同一本书的小说章节与漫画页共用该书词库。

## 3. P0-2 语音输入

### 3.1 目标

- 本地离线，不上传音频。
- 中英文混说，不翻译，按说的写。
- 边说边出字，不等一整句说完。
- 说话途中能插标点、删字、移动光标，听写不中断。
- 本书词库作为热词，同音/近音自动换成正确写法。

### 3.2 引擎选择

优先组合：

1. **sherpa-onnx**（GitHub `k2-fsa/sherpa-onnx`）
   - 流式识别，延迟低，Windows / Linux / macOS / Android 都有原生支持。
   - 用中英双语 streaming zipformer 模型，专门处理中英混说。
   - 内置 VAD / 端点检测，适合长时间听写。
2. **whisper.cpp**（GitHub `ggerganov/whisper.cpp`）
   - 多语言兜底和整段复听；用户说其他语言时切它。
   - 量化模型，CPU 可跑。

原则：

- 实时字幕用 sherpa-onnx，整段高精度复听用 whisper.cpp。
- 模型许可、商用条款在落地前核对，必须允许随 Chapter 分发。
- Android 优先内置轻量中英流式模型，保证开箱可用；桌面首次使用下载并缓存。
- 模型体积、内存、首字延迟实测后再定最终档位，不在计划里拍脑袋。

### 3.3 流式出字

- 麦克风 16k 单声道 PCM，20ms 一帧。
- 每 300–600ms 更新一次稳定文本；不稳定尾巴只做“影子文字”，不写进正文。
- 停顿 0.6–1s 提交一段，按停顿长短补 `，` 或 `。`。
- 不自动停麦；用户点停止或切走才停。

### 3.4 边听边改

- 已提交的文字是正常正文，可随便改。
- 影子尾巴不占正文；用户一按键、点鼠标、移光标，先把影子尾巴提交，再从新光标位置继续听写。
- 用户插标点、删字、换行，听写流不断，不重录、不回滚已提交内容。
- 只有“当前未提交尾巴”会被下一次识别刷新；已提交内容永不回改。

### 3.5 热词与同音替换

- 本书词库全部作为热词传给识别引擎。
- 识别结果再过一遍 2.3 的拼音规则：
  - 无声调完全一致且候选唯一 → 自动替换为词库写法。
  - 多个同音候选 → 不自动改，标红给建议。
  - 声调不同 → 只建议，不自动改。
- 例：说“念七” → 自动成「廿七」；说“小方”被识别成“小芳” → 自动成「小方」。

### 3.6 UI

- 小说编辑器工具栏加麦克风按钮；漫画气泡编辑框也加。
- 状态：未启用 / 请求权限 /  listening / 暂停 / 出错。
- 说话时按钮显示波形和计时；停止后焦点回到原光标。
- 麦克风权限：
  - Android：`RECORD_AUDIO`，首次点按请求；拒绝时给系统设置入口。
  - macOS：`NSMicrophoneUsageDescription`。
  - Windows：系统隐私设置检查。
- 不显示“云端识别”，所有文案明确“本地识别”。

### 3.7 技术落点

- 桌面：Rust 音频采集 + sherpa-onnx C API；Tauri event 推 partial/final。
- Android：Kotlin `AudioRecord` + sherpa-onnx Kotlin/Java API，前台服务保证锁屏短时不断；桥接 Tauri。
- 前端：`useVoiceInput` 管状态、光标锚点、影子尾巴、提交与撤销。
- 不在 WebView 里直接拿 `getUserMedia` 走云端；不依赖 Google/系统在线语音。

### 3.8 验收

- [ ] 说中文，0.6s 内屏幕出现第一段字，不是整句结束才出现。
- [ ] 中英混说「小方说 this is a test 然后念七」→ 中英文都保留，不翻译。
- [ ] 「念七」自动成「廿七」；「小芳」自动成「小方」。
- [ ] 说到一半点逗号、删一个字、移动光标，听写继续，已写内容不被覆盖。
- [ ] 停止后文字留在正文，`Ctrl+Z` 能整段撤回。
- [ ] 断网仍可用。
- [ ] 手机切后台 10 秒内回来，听写状态可恢复或明确停止，不崩。
- [ ] 连续说 3 分钟不漂移、不重复整段。

## 5. P1 内容工具补缺

### 5.1 角色关系图（补强，不是从零做）

现状：`LoreGraph.tsx` 已有节点拖拽、连线、关系标签、坐标保存。
还差：

- 节点类型：角色 / 地点 / 物品 / 组织，不同图标和颜色。

- 多关系曲线避让，不全部挤成一条直线。

- 缩放、平移、适应画布、只看某角色的一跳关系。
- 手机端只读浏览 + 点节点看详情；编辑留桌面。

### 5.2 场景板

现状：`Scene` 只有 `title / summary`，场景卡挂在章下，没有时间、地点、排序。

扩展字段：

```ts
interface Scene {
  id: string;
  title: string;
  summary: string;
  timeText?: string;      // 显示用：第一天黄昏
  timeOrder?: number;     // 排序用，可空
  place?: string;         // 地点名
  placeId?: string;       // 关联 Lore 地点
  characterIds?: string[];
  chapterId?: string;
  order?: number;
  color?: string;
}
```

视图：

- 时间线：横向按 `timeOrder` 排，未定时间进“待定”区。
- 地点泳道：按 `place` 分横条，场景卡在泳道里拖。
- 拖拽只改 `order / timeOrder / place`，不改正文。
- 点卡片跳到对应章；筛选按卷、角色、地点。
- 手机长按拖动，横向滚动不误触。

### 5.3 封面设计器

现状：内置封面库 + 自定义图裁切，没有排版编辑。

范围控制：

- 模板：纯色 / 图片 / 图片 + 色块 / 极简字标。
- 元素：书名、副标题、作者、系列标、书脊色。
- 图片：缩放、移动、焦点裁切；不做完整图层编辑器。
- 导出 1600×2133 PNG，同时写回 `book.json` 的封面字段。
- 每本书独立保存；不覆盖内置封面库。

### 5.4 脚注

- 正文插上标数字，`Chapter` 增加 `footnotes?: Footnote[]`。
- 编号按章或按书，规则跟章节编号设置走。
- 点击上标滚动到章末脚注；再点回正文。
- 导出 HTML / 打印 / EPUB 时保留；纯文本导出退化为 `[1]` + 文末列表。
- 手机端可查看、可新增，不要求复杂排版。

### 5.5 章节编号规则

`BookMeta` 增加 `numbering`：

```ts
interface NumberingRule {
  unit: "chapter" | "hui" | "volume";
  style: "arabic" | "chinese";
  pattern: string;        // 第{n}章 / 第{n}话 / {n}.
  startAt: number;
  perVolumeRestart: boolean;
  specialPrefix?: string; // 序章 / 番外
}
```

- 新建章按规则自动命名。
- 已有章改名必须**先预览**再应用，不静默批量改。
- 目录、导出、打印共用同一套编号，不各写一份。
- 卷、章、话分别有开关；漫画用“话”。

## 9. 默认决策（有异议明天开工前改）

1. 词库文件：每本书 `proofread.json`，不共享、不联网。
2. 最小词长：默认 2 字；单字需手动开启且只认同调异字。
3. 词条上限：300 条/书；单章问题展示上限 2000 条。
4. 忽略：只忽略当前一处，按上下文指纹记忆。
5. 词库弹窗：桌面最大 `720×640`，手机最大 `76dvh`，超出只滚列表。
6. 语音引擎：sherpa-onnx 流式为主，whisper.cpp 多语言兜底。
7. 语音提交：300–600ms 一段，影子尾巴不入正文；任何编辑先提交尾巴。
8. 热词替换：无声调同音且候选唯一才自动；多候选/声调不同只提示。
9. 目标版本：`1.8.0`；1.7.0 已发布包不改。
10. 漫画布局优先于新增画世界 Pro 功能。
