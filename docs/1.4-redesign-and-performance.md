## P0｜性能：整体迟钝、滚动卡顿

目标不是“看起来有懒加载”，而是真正跟手。

- [ ] 整体交互延迟排查：点击、切换、输入、滚动逐项测响应时间，找出长任务和强制重排。
- [ ] 长文滚动专项：20 万字《小方趣生活2》已明显卡顿，不能出现“一张一张”或延迟几秒。
- [ ] 大文档按可视区域渲染：编辑区/阅读区只挂载视口附近内容，避免整本 DOM 全量参与布局与绘制。
- [ ] 滚动监听不触发 React 高频重渲染；滚动位置与进度用 rAF + CSS transform，不在 scroll 回调里同步计算全文字数/布局。
- [ ] 排查 `backdrop-filter`、大面积渐变、阴影、滤镜、3D 变换在非必要页面的常驻开销。
- [ ] 减少布局抖动：批量读、批量写；避免滚动中查询 `getBoundingClientRect` 造成强制同步布局。
- [ ] 长文首屏、切章、切卷、目录展开都要做增量更新，不整书重算。
- [ ] 用真实数据验收：20 万 / 50 万 / 100 万字三档，滚动与输入不得出现秒级停顿。
- [ ] 验收指标：滚动稳定 60fps，单帧尽量 < 16ms；输入无感知延迟；切书/切页无白屏。

## P0｜纠正 3D 书与 2D 封面的使用场景

当前现象反了：工作台出现 3D 书，切书页反而没有 3D 书。

正确规则：

- [ ] 工作台当前书：只展示 **2D 小说封面**，不要 3D 书模型。
- [ ] 极简首页书架：只展示 **2D 小说封面**。
- [ ] 书籍介绍页左上角：只展示 **2D 小说封面**。
- [ ] 顶栏书标：只展示 **2D 小说封面**。
- [ ] 3D 书只在“切换书籍 / 3D 书架”场景出现。
- [ ] 点击工作台封面进入切书页时，封面不是飞向左上角消失，而是移动到屏幕中央，顺势变成切书页的中心书。
- [ ] 其余书在中心书落位后，从两侧/后方平滑出现，错峰过渡，不突然弹出。
- [ ] 退出切书页同理，反向平滑回到工作台封面，不闪断。
- [ ] 切书页的 3D 书必须存在且可交互；修复当前“切书页没有 3D 书”的回归。

## P0｜封面必须全站复用同一套素材与组件

用户明确要求“素材复用”，不能一个页面一种封面。

- [ ] 建一个唯一的封面组件/渲染源：同一本书在工作台、极简书架、介绍页、顶栏、3D 书正面显示同一张封面。
- [ ] 自定义封面：直接使用书籍目录内复制后的封面文件。
- [ ] 默认封面：只保留一套生成规则和同一套排版，不允许出现“一个大字”的占位封面。
- [ ] 3D 书正面的封面与 2D 卡片封面必须像素级同源，不再分别生成两套配色/排版。
- [ ] 书籍介绍页左上角封面必须与书架卡片一致。
- [ ] 检查所有出现书籍封面的页面，统一走同一个组件。

## P1｜更换封面：3:4 建议、自由比例裁切、复制而非移动

- [ ] 点击“更换封面”打开系统文件选择器。
- [ ] 选择后给一个轻量提示：建议 3:4，其他比例也可以，会按 3:4 居中裁切。
- [ ] 小字提示要低调，不抢主操作，不突兀。
- [ ] 提供裁切预览，确认后才生效。
- [ ] 生效时执行“复制”而不是“移动/重命名”原图：把图片复制一份到该小说的书籍目录（如 `assets/cover-<timestamp>.<ext>`），再更新 `book.json` 的 `cover` 指向复制后的文件。
- [ ] 原图之后被移动、重命名、删除，都不能影响书封面。
- [ ] GUI 与 MCP 的 `set_cover` 共用同一套复制逻辑，避免两套行为。
- [ ] 替换旧封面时不要误删用户原图；旧副本可按策略保留或仅在书籍目录内清理。

重点文件：
- `src/components/Modals.tsx` / 封面选择相关组件
- `src/lib/api.ts`
- `src-tauri/src/lib.rs`（`set_cover` 及复制落盘逻辑）

## 2026-11-22 追加观察：切书页视觉上已经没有 3D

- 最新交付截图第一张（《小方趣生活2》）与第二张（《长夜将尽》）封面本身不同，但姿态看起来像同一张平面卡片：只能看到正面和一条很窄的纸边，没有明显厚度、书脊、书口或透视。
- 原因：为避免相邻书干扰，切书页只渲染当前一本；默认角度归零；鼠标倾斜幅度过小。3D 模型和六个面虽然存在，但正面视角下几乎等于 2D 封面。
- 明天修正目标：切书页必须一眼看出是 3D 书（可见书脊、书口、上下切口与轻微透视），同时保持面向鼠标；不能再出现相邻书白块；工作台仍必须是纯 2D 封面。
