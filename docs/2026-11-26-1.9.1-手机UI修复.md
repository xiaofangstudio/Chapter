# Chapter 1.9.1 手机端 UI 修复

## 修复内容

- 顶部统一避让状态栏、摄像头孔：欢迎页、工作台、书籍顶栏、作品介绍、导入书稿、封面设置、书架聚焦页全部使用原生 `--sat` inset，CSS 兜底 24px。
- 禁止整页双指缩放：WebView 关闭 `supportZoom` / `builtInZoomControls` / `displayZoomControls`，viewport 加 `maximum-scale=1, user-scalable=no, viewport-fit=cover`。
- 封面裁切恢复 3:4：手机端裁切框改为固定 `240 × 320`，不再被纵向 flex 压成 1:1。
- 书架聚焦页锁死纵向滚动：`touch-action: none`、`overscroll-behavior: none`，覆盖层打开时底层页面同步锁定。
- 手机端留白回补：放宽页面左右边距、卡片间距、章节行高、底部操作区，给手势条留出安全距离。
- 版本号升到 1.9.1，Android versionCode 1009001。
