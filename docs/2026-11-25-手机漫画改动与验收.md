# Chapter 1.7.0 手机漫画改动与验收

> 日期：2026-11-25
> 目标：桌面与 Android 功能一致，手机 UI 单独重做，不把桌面三栏硬缩进窄屏。

## 1. 手机工作区结构

窄屏（≤820px）下桌面 `comic-toolbar` 隐藏，改为两行玻璃 Dock：

- 上行：撤销、重做、笔刷、页面（页数角标）、图层（图层数角标）、缩放、更多。
- 下行：选择、画笔、橡皮、填充、吸色、颜色。
- 顶部作品导航压成单行四等分：作画 / 大纲 / 设定 / 世界观。
- 页面、图层、进阶工具、滤镜全部走底部 sheet；图层检查器改为纵向布局。

“更多”里补了手机原先无法进入的入口：气泡、手绘格、拖格、模板、图片、进格、多选、磁吸、页面、图层、保存，以及任意图形和液化。

## 2. 图层数量上限

按用户指定，图层列表固定只展示约 4.5 行：

- 手机 `.comic-layer-list`：`height/min-height: 214px`，`overflow-y: auto`。
- 桌面同组件 `max-height: 214px`，超出同样滚动。
- 少图层时保留同样的 214px 空位，不顶动下方“不透明度 / 混合 / 剪贴蒙版 / 新建 / 删除 / 翻转 / 复制 / 剪切 / 粘贴 / 颜色与笔刷”。
- 行高不再被 flex 压缩，滚动条常驻留位，避免横向抖动。

## 3. 本轮补进的画世界 Pro 能力

- 液化·推移：按圆形笔迹从上一落点搬运像素，径向羽化；半径与力度可调；一次拖动只进一次撤销。
- 笔刷对称：关 / 左右 / 上下 / 四向；镜像轴按当前格或并集外框中线计算。
- 等比：手机没有 Shift，用按钮锁定正方 / 正圆 / 45° 线。
- 触屏并集：新建、加选、减选，补手机没有 Shift / Alt 的选区合并。
- 页面长按删除（560ms + 震动）、色板长按移除（520ms）。
- 进格、保存、页面、图层进入进阶面板，窄屏不再依赖隐藏的桌面按钮。

## 4. 电脑 ↔ 手机互传

`src-tauri/src/sync.rs` 原先只收小说目录，漫画工程不会进包。现在：

- 以 `comic/` 前缀递归收集 `project.json`、每页 `page.json`、图层 PNG、素材、缩略图。
- 只收 `json / png / jpg / jpeg / webp`，跳过隐藏文件、`.tmp`、`.part`。
- `validate_rel_path` 允许 `comic/`，仍拒绝 `..` 路径穿越。
- 传输类型增加 `comic`，界面清单显示漫画工程、页、图层、素材、缩略图。

新增单测：

- `sync::tests::comic_paths_are_collected_and_allowed`
- `sync::tests::comic_package_applies_to_book`
