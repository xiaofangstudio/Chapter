## 0. 一句话结论

Chapter 不再是“小说制作软件”，但也不是 OC 平台，而是一个 **书本平台**：文字书、漫画书都用 Chapter 这个概念，书仍然是主对象；名字不变，只在现有书上加功能。

漫画书在新建时必须和文字书区分：小说卡是摊开的横线书页，漫画卡是摊开的线框+淡线稿书页，一眼能分清；选定后进入对应工作台，而不是把文字编辑器套一支画笔。

书组只做很小一层：允许把几本书连成“同一世界观/同一系列”，共享书名、简介、角色三视图等最少数据；不做全局 OC 库、关系网、时间线、素材库、声音档案、公开主页。

核心操作链固定为：拖模板/拖框铺格 → 单击选中、框选多格 → 双击进格聚焦，只留当前格放大画 → 退出 → 放气泡、拉大缩小、双击打字/画字。手机端始终竖屏、是正式绘画端，不是缩水预览端；外部图片可直接放进线框内部。

绘画内核直接复用 Strata 的成熟能力，但漫画工作台的分格、气泡、跨格绘制、角色三视图、漫画专用笔刷与网点、页面/话的管理、导出和手机同步，必须按漫画重新设计。

Strata 是修图软件，它的笔刷、图层、蒙版、文字、选区、变换、PSD 能力可以直接搬；它的照片滤镜、修脸、HDR、全景、液化这些不需要整套搬进 Chapter。i18n 从第一天留 key，正式翻译放最后。

## 1. 产品目标与非目标

### 1.1 目标

1. 新建书时明确选择 **小说 / 漫画**，后续工作台、目录、统计、导出、同步都按类型走不同路径。
2. 漫画书可以完成从“分格 → 草稿 → 线稿 → 网点/上色 → 气泡/文字 → 导出”的完整闭环。
3. 画画时可以选择单格、多格或跨格绘制；跨格画一条线不能把中间的装订缝也画上。
4. 气泡可拖拽、可改形状、可改尾巴、可填字、可做艺术字。
5. 角色设定能存三视图、表情、姿势、配色，并在画某一格时随手调出参考。
6. 漫画内容能进入现有的手机互传：只传改过的页和素材，方向、确认、真实进度、不退出提示都要保留。
7. 所有小方工作室软件自带 MCP；漫画也要能被外部 AI 读取和控制，但删除、覆盖等破坏性操作必须确认。
8. 新建书的“小说/漫画”选择必须有明确的视觉：小说是摊开的横线书页，漫画是摊开的线框+淡线稿书页；这套视觉在手机端也要成立。
9. 手机端不是只读端，而是第一等绘画设备：单格聚焦、压感笔、防误触、气泡编辑都要能完成；电脑端和手机端共用同一套数据结构。
10. 所有新增文案从第一天走 i18n key；正式翻译放最后，功能稳定后一次性补齐，避免返工。
11. Chapter 保持“书本平台”定位：书是主对象，文字书和漫画书并列；不做 OC 平台，不把首页改成角色库。
12. 只做小范围书组关联：几本书可以标成同一世界观/同一系列，共享最少量的角色三视图和简介，方便跨书对照，不做全局角色档案。
13. 手机端始终竖屏，不做横屏，也不做左右摇杆式布局；竖屏是唯一主路径，平板默认也竖屏。

### 1.2 第一版明确不做

- 不做 3D 人物摆姿势、不做 3D 场景渲染。
- 不做漫画动画、分镜视频、Live2D。
- 不做云端协作、多人实时同画。
- 不做 AI 自动生成漫画/自动上色（可以以后单独立项，不能混进第一版）。
- 不把 Strata 的完整照片修图工具链搬进 Chapter。
- 小说书默认不显示画板；以后若需要“单幅插图板”，单独设计，不和整页漫画混在一起。
- 不做 OC 平台：不做全局 OC 首页、OC 档案、关系网、时间线、声音档案、素材库、公开主页、OC 卡。
- 不做自动把同名角色合并成一个角色；书组共享也要用户手动勾选。
- 不做手机/平板横屏布局；手机与平板都锁竖屏，桌面端三栏不受影响。

## 2. 新书流程：先定类型，再谈工作台

### 2.1 新建书第一步

新建书弹窗第一屏只做一件事：选择书类型。

- **小说**：现有流程不变。
- **漫画**：多一步漫画设置，然后进入漫画工作台。

#### 2.1.1 类型选择卡片的视觉（不是纯文字按钮）

这一屏必须让用户一眼看懂“我要做的是哪一种书”，不能只放两个文字按钮。

**小说卡**

- 主体是一本**摊开的书**，左右两页，中间有书脊阴影。
- 页面上是等距**横线**，像稿纸/横线本；横线浅灰，不抢文字。
- 书的边缘有纸张厚度、轻微投影；整体偏暖白。
- 选中时书本轻微抬起（translateY -6px），描边变成主题色，横线从左到右扫过一遍。

**漫画卡**

- 同样是**摊开的书**，但页面上是**分格线框 + 很淡的铅笔线稿**。
- 线框是清晰的黑色/深灰细线，2～3 个格；线稿只做“有人物、有背景”的暗示，透明度约 8%～12%，不能喧宾夺主。
- 线框里可以有一格是留白，暗示“这里等你画”。
- 选中时线框依次亮起，像画格被勾出来。

**共同规则**

- 两张卡等宽、等高，书的大小一致，只有页面内容不同；不要让漫画卡看起来更“高级”或小说卡更“廉价”。
- 卡片下方标题用“小说”“漫画”，再各加一句说明：
  - 小说：`一章一章写下去，适合纯文字长篇。`
  - 漫画：`先分格，再画画，适合页漫、条漫和四格。`
- 卡片整体可点击，不是只有按钮可点；键盘 Tab 可聚焦，Enter 选中。
- 鼠标悬停时书本再打开约 2°，不做夸张 3D 翻转；低配设备自动关闭动效。
- 两张卡都用同一套插画语言，后续可以替换成用户自己的封面/模板预览，但结构不变。

**手机端适配**

- 手机竖屏不并排挤两张卡，改为**上下两张全宽卡片**。
- 书仍然保持“摊开”的形态，按容器宽度等比缩放，不裁掉书脊；横线/线框在缩小时仍可辨认。
- 卡片高度控制在 160～200px 内，标题和说明在书的下方，不叠在书页上。
- **手机端始终竖屏，不做横屏布局**：用户旋转手机时，页面保持竖屏比例并提示“请竖屏使用”，不自动变成左右三栏。
- 平板也锁竖屏；不提供横屏三栏主布局，桌面端才有三栏。
- 点按卡片有轻微触感反馈；选中后底部出现“继续”按钮，避免误触直接建书。

**i18n**

- 文案不要写死在卡片组件里；从一开始就用 key：`newbook.type.novel.title`、`newbook.type.novel.desc`、`newbook.type.comic.title`、`newbook.type.comic.desc`。
- 插画本身不含文字；如果书页里要放“示例字”，用可替换的占位字形，不参与翻译。

漫画设置项：

| 设置 | 选项 | 默认 |
|---|---|---|
| 漫画形态 | 页漫 / 条漫 / 四格 | 页漫 |
| 页面尺寸 | A4 / B5 / 方形 / 自定义毫米 | B5 |
| 分辨率 | 300 / 600 dpi | 300 dpi |
| 色彩 | 黑白 / 灰阶 / 彩色 | 黑白 |
| 阅读方向 | 左→右 / 右→左 | 左→右 |
| 初始分格模板 | 空白 / 2×2 / 3×2 / 四格 / 大格+两小格 / 斜切动作格 | 2×2 |
| 初始页数 | 1 / 4 / 8 | 1 |
| 是否同时建“话” | 是 / 否 | 是 |

### 2.2 类型锁定与迁移

- `book.json` 增加 `kind: "novel" | "comic"`，老书没有这个字段时按 `novel` 处理，保证向后兼容。
- 类型创建后锁定，不在设置里随便切换，避免正文、页、统计、导出全部错位。
- 如果用户真要把小说改成漫画，只提供“另存为新的漫画书”，原书不动；反向同理。

### 2.3 漫画书的层级

沿用现有“卷”的概念，但把“章”解释成“话”：

```
书
└─ 卷
   └─ 话（对应现有 Chapter）
      └─ 页（新增 ComicPage）
         └─ 格 / 气泡 / 图层
```

- 每一话可以有独立的 Markdown 脚本，写到“第1格：小方推门，近景，惊讶”。
- 话仍然进入现有大纲，所以漫画也能用大纲、设定、世界观、搜索。
- 页不进入小说字数统计；漫画统计改成“页数 / 格数 / 气泡数 / 台词字数”。

## 3. 漫画工作台的信息架构

### 3.0 标准操作流：用户的真实动作顺序

这一节不是功能清单，是“用户从空白页到画完一页”的实际路径。所有 UI 都按这条链路设计，不能把功能散落在五个面板里。

**第一步：铺格**

1. 新建漫画书后进入空白页，页面中央不是空白画布，而是一个提示：“先把格子铺上”。
2. 底部/右侧打开“分格模板”抽屉，模板以缩略图卡片展示。
3. 用户可以把模板**拖到页面上**，也可以点一下模板直接套到当前页；拖入时显示落点预览和格子数量。
4. 也可以从“空白格”开始，一次拖一个框，拖几个都行；框可以移动、缩放、旋转、改形状。
5. 铺完格后，页面进入“分格模式”，此时画画工具收起，避免误画。

**第二步：选中格**

- 单击格：选中该格，显示八个缩放手柄、边框、阅读序号。
- `Shift` 单击 / 框选：多选格，用于一起移动、一起画、一起改边框。
- 双击格：进入**格内聚焦绘制**（见 3.0.1）。
- 双击多选中的任意一格：进入**多格并集聚焦**，所有选中的格一起放大，gutter 仍然断开。

**第三步：进入格内画画**

1. 双击后，页面切换为“单格聚焦”：选中的格放大到工作区 90% 左右，其他格隐藏或只留 5%～10% 的淡水印。
2. 如果只选了一个格，就只留这一个格；如果是多选，就把选中的格按原相对位置一起放大，未选中的全部隐藏。
3. 格的边框在聚焦时变成浅色参考线，不遮挡笔迹；可以一键隐藏。
4. 画布四周留出“越界区”：允许笔迹画出格边，但默认被格的 alpha 蒙版裁掉；打开“超出格”开关后，越界笔迹保留（见 4.7）。
5. 画完点“返回整页”或按 `Esc`，回到原来的页面缩放和滚动位置，不重置视图。
6. 画的过程中自动保存；退出不会弹“是否保存”，只会显示一个短暂的“已保存”。

**第四步：放气泡**

1. 回到整页，选择“气泡”工具，在页面上拖出一个气泡；拖拽时实时显示气泡大小。
2. 气泡有八个缩放手柄和尾巴控制点；拉大拉小、拖尾巴都直接操作，不弹属性窗。
3. 双击气泡内部：进入文字编辑，出现光标，直接打字；文字自动内缩、自动换行。
4. 双击已有文字：全选当前文字，方便替换；`Esc` 退出编辑，`Ctrl+Enter` 也可确认。
5. 想在气泡上“画字”：切到艺术字/笔迹层，直接在气泡范围内写；笔迹可以绑定气泡，跟随气泡移动和缩放（见 6.5）。
6. 气泡默认在格之上、文字在气泡之上；气泡可以钉在格上跟着走，也可以钉在页面上不跟格。

**第五步：检查与导出**

- 点“阅读预览”，按阅读方向逐格高亮，检查气泡是否挡脸、字是否出框、跨格人物有没有断在 gutter 里。
- 导出前跑一遍检查：空格、文字溢出、分辨率不足的外部图片、未嵌入字体、出血不足。
- 导出 PNG/PDF/PSD/CBZ；手机端可以只看预览和分享，完整导出回电脑做。

#### 3.0.1 格内聚焦（Focus Mode）的硬规则

- **只留当前格**：单格聚焦时，其他格不显示内容，最多留极淡的轮廓，避免用户以为还能画到旁边。
- **放大但不失真**：聚焦是视图缩放，不改页面实际尺寸、不改 dpi、不栅格化。
- **边框可隐藏**：画画时边框是参考线，可一键隐藏；导出时边框按格的设置恢复。
- **手势退出**：手机上双指捏合缩小到一定程度，或点左上角“返回整页”，退出聚焦；不依赖手机返回键。
- **状态保留**：退出后保留当前页、当前格、当前工具、当前笔刷、缩放位置。
- **多格聚焦**：多选格时，按并集显示；未选中的格内容全部隐藏，gutter 自动用蒙版断开。
- **空白格**：双击空白格也能进，进去就是一张空白纸，不要求先有内容。

#### 3.0.2 一切按用户体验来：交互原则

- **直接操作优先**：能拖就不弹窗，能双击就地编辑就不开右侧面板。
- **一层一件事**：铺格时只让你铺格，画画时只让你画画，放气泡时只让你放气泡；工具模式明确。
- **不打断**：自动保存、后台合成、后台同步；除了删除页/覆盖冲突，不用确认框打断。
- **可撤销**：移动格、改边框、画画、气泡文字、导入图片全部进同一套撤销栈；`Ctrl+Z` / 双指撤销。
- **可退出**：任何聚焦、预览、全屏都有明显返回；`Esc` 永远能退一层。
- **空状态有下一步**：空白页不是空白，给“铺格”“套模板”“导入图片”三个入口。
- **触控与鼠标等价**：双击 = 双击，右键 = 长按，悬停才有的事在手机上必须有替代。
- **低配不卡**：大页面用瓦片渲染；动效可关；手机端默认只渲染当前页和相邻页缩略图。

### 3.1 主界面

下面是“进入某一话漫画之后”的工作台；书单与书组视图仍沿用现有工作台，见 20.3。

```
┌ 顶部：返回 / 书名 / 话标题 / 模式切换 / 保存 / 导出 / 互传 / 设置 ┐
├──────────────┬──────────────────────────────┬─────────────────────┤
│ 左：话与页     │ 中：画布（整页 / 单页 / 双页） │ 右：图层 / 属性 / 素材 │
│ 缩略图列表     │ 标尺、分格、气泡、选区        │ 角色 / 网点 / 模板     │
├──────────────┴──────────────────────────────┴─────────────────────┤
│ 底部：画笔 橡皮 填充 选区 分格 气泡 文字 尺规 手形 缩放            │
└──────────────────────────────────────────────────────────────────┘
```

三种模式：

1. **分格模式**：主要操作格子、边框、 gutter、页面模板；画画工具收起。
2. **绘制模式**：默认进入选中格；笔刷、图层、选区、气泡可用。
3. **阅读预览**：隐藏辅助线，按阅读方向显示单页/双页/条漫连续流；可检查气泡是否压字、裁切是否出错。

### 3.2 左栏

- 话列表：上一话 / 下一话、话标题、页数。
- 页缩略图：拖拽排序、复制页、插入页、删除页、设置跨页。
- 页状态：草稿 / 线稿 / 完成；仅作标记，不强制。
- “新建页”可以按模板批量生成，比如一次生成 8 页 2×2 草稿。

### 3.3 右栏

Tab 分组：

- **图层**：页级图层 / 格内图层 / 跨格图层；组、蒙版、剪贴、混合模式、锁定、颜色标签。
- **属性**：当前笔刷、当前格、当前气泡、当前文字。
- **素材**：角色三视图、表情、姿势、网点、速度线、气泡形状、默认模板。
- **页面**：尺寸、出血、安全框、阅读方向、页码。

## 4. 分格系统：漫画的骨架

### 4.1 格（Frame / Panel）对象

每个格不是一张图片，而是带裁剪范围的容器：

- 形状：矩形、圆角矩形、斜切四边形、自由多边形、贝塞尔曲线形。
- 边框：粗细、颜色、内外描边、手绘抖动、无边框、出血格。
- 间距：格与格之间的 gutter，可全局设，也可单边设。
- 层级：格可以前后移动；气泡和文字通常在格之上。
- 锁定：锁定后不能误拖，但仍可在格内画。
- 命名：第1格、第2格……用户可改名。
- 阅读序号：显示 1、2、3，导出预览可隐藏。

### 4.2 拖拽与组合

- 拖动格边框：默认 **格 + 格内内容一起移动**，符合漫画“挪这一格”的直觉。
- `Alt` 拖动：只移框、不移动内容，用来改裁切范围。
- 多选格：一起移动、对齐、等距分布、统一边框、统一 gutter。
- 成组：把几个格设为一组，一起缩放/旋转；但组内仍可单独画。
- 合并格：把两个格并成不规则大格，内容按各格裁剪保留。
- 拆分格：一刀切成两格，可横切、竖切、斜切。
- 复制格：连同格内图层和气泡一起复制；也可只复制框。

### 4.3 默认模板

第一版至少提供：

- 四格：起承转合。
- 2×2、3×2、3×3。
- 上大下二、上二下大。
- 单页大格 + 两小格。
- 跨页大格。
- 斜切动作格。
- 横条叙事格。
- 条漫：3～5 个纵向长格。
- 空白自由格。

模板不是固定图片，是可直接编辑的格对象；套用后可以拖、改、删、重排。

### 4.3.1 当前已实现（2026-11-24）

模板库按三组呈现，不再把方方正正的格子统称“漫画”：

- **连环画**：六格、四格、电影条、大场面、三连。保留方正、横平竖直的传统连环画/条漫底子。
- **漫画**：切角四格、斜切三格、放射五格、错位四格。全部由斜边、错位、切角或放射状四边形组成；预览也按真实多边形绘制，不再用矩形示意。
- **整页**：无边框，一张画铺满整页。

四边形分格的数据不是截图，也不锁死：

- 每格存 `shape: "quad"` 和相对包围盒的四个归一化角点；缩放分格时角点跟着走。
- 点击、框选、双击入格、格内画笔、气泡、图片、页缩略图、格内聚焦预览都按真实多边形命中与裁剪；格内落笔只在四边形内部生效。
- 选中四边形时，四个角各有一个手柄，可逐角拖动改形；整格仍可拖动移动。改角后包围盒、角点、图层画布会同步更新。
- 支持凹四边形；四点自交、面积过小会拒绝，不会生成“蝴蝶结”格。

**手绘格（用户自己画格）**：

- 工具栏“手绘格”或模板弹窗“手绘一格（点四个角）”进入手绘模式。
- 在页面上依次点四个角，前三个点显示橙色虚线预览和“第 n / 4 个角”；第四点落下即生成一个四边形分格，并自动选中、切回选择工具。
- `Esc` 取消本次未完成的四个点；切页或切工具会自动清空未完成草稿。
- 四点自交或面积太小时在状态栏提示重画，不产生格。
- 进入手绘模式时会先清空已选中的格和气泡，页面上只留下橙色草稿线，避免旧手柄与草稿混在一起。

改形和覆盖的边界行为：

- 拖动角点改形后，撤销会同时恢复旧包围盒与旧图层画布；重做会按重做后的包围盒重新铺图层画布，不会出现框变大、画布仍停在旧尺寸的情况。
- 套模板会同时清空该页的格、气泡和图片；页面只有气泡或只有导入图片时，也会在覆盖前提示确认，不再只看是否有笔迹。
- 模板弹窗脚部的“加矩形格 / 加无边框整页 / 手绘一格”执行后自动关闭弹窗，不会把用户留在弹窗里看不到结果。

模板库还要满足“很多预设”的实际使用：

- 分类：基础格数、对话、动作、大场面、四格、条漫、跨页、留白/无框。
- 每个分类下至少 6～10 个变体；总数第一版不少于 40 个，后续可扩展。
- 模板卡片显示格数、阅读方向、适合的场景，不显示内部 ID。
- 支持搜索（“三格”“斜切”“大格”）、收藏、最近使用；手机端只显示大卡片横向滑动。
- 拖入页面后，模板变成可编辑格；不会锁死，也不会自动填充线稿。
- 页面可以混用模板：上半页套 2×2，下半页手拖两个框；允许重复套用并叠加。
- “空白格”模板永远排第一，保证用户能从零开始拖几个框。

### 4.4 格的裁剪语义

- 每格有独立裁剪形状。
- 格内图层默认被格形状裁剪。
- 页级背景/出血画面不被格裁剪。
- 一个图层可以同时被多个格裁剪，用于跨格人物或大场景。
- 格边框绘制在最上层，不被内容盖住；也可设为“边框在内容下”。

### 4.5 跨格绘制（关键）

用户明确要求：可以选中一个格画，也可以框选一系列格一起画，因为很多人喜欢跨格画。

实现语义：

| 模式 | 落笔范围 | 适合 |
|---|---|---|
| 当前格 | 只裁到当前选中格 | 普通分格画 |
| 选中多格 | 裁到所有选中格的并集 | 人物跨两格、动作跨三格 |
| 跨格图层 | 图层绑定多个格，笔迹连续，gutter 自动断开 | 一条长线/披风/雨跨格 |
| 页级 | 不裁格，整页可画 | 背景、出血、页边装饰 |
| 格内新建 | 每次落笔自动建/选当前格图层 | 新手默认 |

跨格不是把一条线复制到每个格，而是：

1. 取所有选中格的形状。
2. 求并集。
3. 把并集做成一个临时 alpha 蒙版。
4. 笔迹只在这个并集内落下，gutter 自然断开。
5. 导出时仍按整页合成，不额外拼图。

这样用户看到的是“一条连续的线”，但装订缝里没有墨。

### 4.6 框选多个格：不是“批量操作”，是“画一张大画”

用户框选多个格，往往不是为了批量改属性，而是因为：

- 人物要跨两格，头和身体不能断。
- 场景要“没有格子”，像一整张插画，只是被几个框切开。
- 动作、雨、烟、披风、长镜头要穿过 gutter。

所以多选格必须支持三层能力：

| 层级 | 操作 | 说明 |
|---|---|---|
| 选择 | 单击、`Shift` 单击、拖框、点“全选” | 选择状态必须明显，每个格有编号和描边 |
| 批量编辑 | 一起移动、缩放、对齐、等距、统一边框/gutter | 改的是格对象，不动格内像素 |
| 一起画 | 双击任意选中格进入“并集聚焦” | 笔迹落在所有选中格的并集里，gutter 断开 |

交互细节：

- 拖框选择时，只要框碰到格边框就算选中，不需要完全包住。
- 多选后右侧显示“已选 3 格”，提供“一起画”“合并”“删除”“取消选择”。
- “一起画”不是把所有格拼成一张图，而是保留每格独立图层，只共享一个临时并集蒙版；退出后每个格的图层仍可单独编辑。
- 多选状态下双击，默认进“一起画”，不进入单格；如果用户想单格，先单击取消其他选择。
- 框选时可以反选（`Alt` 拖框）排除不需要的格。
- 手机上用“选择模式”按钮进入多选，点格加选，再点“一起画”；不要求用户会拖框。

### 4.7 超出格 / 无框画法

漫画不是每根线都必须被框住。很多画面要“冲出格子”，或者干脆像一张没有框的插画。

提供三种落笔范围，切换要快：

| 范围 | 笔迹 | 典型用途 |
|---|---|---|
| 格内（默认） | 被当前格 alpha 裁切，出界部分不显示 | 普通分格 |
| 超出格 | 笔迹保留在格边界外，但仍在页面内 | 人物头发/手/武器冲出格 |
| 整页 | 不受任何格裁切 | 无框大场景、出血背景、页边装饰 |

交互：

- 进入格内聚焦后，顶部有一个“超出格”开关；打开后，笔迹可以画出格边，但会用一个“越界提示色”显示超出部分，导出时按开关决定保留或裁掉。
- 多格并集模式下，gutter 仍然断开；如果用户要连 gutter 也画上，切到“整页”模式，并明确提示“这会画到装订缝”。
- 无框画法：新建页时选“空白页/无格页”，或把格的边框设为“无边框”，此时格只是一个裁剪容器，视觉上没有线。
- 一个画面可以同时有“有框格”和“无框插画格”；无框格仍然参与阅读顺序。
- 超出格的内容在缩略图和阅读预览里必须能看出来，不能只在放大后才发现。

## 5. Strata 绘画引擎怎么搬

### 5.1 现状基线

Strata 2.6.3，MIT，React 19 + TypeScript + Canvas2D/WebGPU 桥。以下文件已确认存在，不是设想：

| Strata 文件 | 能力 | Chapter 漫画用法 |
|---|---|---|
| `src/engine/paint.ts` | 笔刷引擎、笔尖、纹理、散布、压感、倾斜、稳定、对称 | 直接作为画笔核心 |
| `src/engine/pen.ts` | Windows Ink / Pointer Events 的 pressure、tilt、twist、eraser | 数位板支持 |
| `src/engine/text.ts` | 横排/竖排、自动换行、字距、行高、弯曲文字 | 气泡文字、艺术字、拟声字 |
| `src/engine/blend.ts` | Canvas2D 不支持的混合模式 | 图层混合 |
| `src/engine/compositor.ts` | 图层合成 | 页面合成 |
| `src/engine/displayCompose.ts` | 显示合成缓存 | 画布刷新 |
| `src/core/layer.ts` | 像素/调整/组、蒙版、剪贴、样式、智能对象 | 图层模型 |
| `src/core/layerOps.ts` | 图层操作 | 合并、复制、栅格化等 |
| `src/core/selection.ts` | 选区 | 画笔限制、填充、网点 |
| `src/core/transform.ts` | 变换 | 移动、缩放、旋转、翻转 |
| `src/core/history.ts` | 撤销/重做 | 需要改造，见 5.3 |
| `src/engine/psd.ts` | PSD 读写 | 导出分层 PSD |
| `src/core/pdf.ts` | PDF 输出 | 多页漫画 PDF |
| `src/engine/exportImage.ts` | 图片导出 | 单页 PNG/JPG/WebP |

不搬：修脸、HDR、全景、液化、相机 RAW、照片滤镜全家桶。保留基础调色/色阶作为可选，不放进漫画主工具栏。

### 5.2 代码组织

不建议 Chapter 直接跨项目 import Strata 源码：

- 两个软件版本、构建、发布互相牵连，一次 Strata 重构会把 Chapter 编译炸掉。
- 但也不建议无脑复制后两边各改一份，最后笔刷行为分叉。

第一版：

- 把需要的引擎模块 **vendor 进 Chapter**，目录 `src/comic/engine/`，文件头保留来源和 MIT 说明。
- 只改接口，不改笔刷算法；保证同一支笔在 Strata 和 Chapter 里手感一致。
- 等漫画稳定后，再抽成 `packages/draw-core` 共享包，反向给 Strata 用。

### 5.3 必须改造的三件事

#### A. 图层表面不能永远整页大画布

Strata 的 `StrataLayer.surface` 是文档尺寸的整张画布。A4 300dpi 约 2480×3508，一层 RGBA 约 34.8MB；20 层就是约 700MB，再叠蒙版和撤销快照，内存直接爆。

漫画必须改成 **瓦片化表面**：

- 256×256 或 512×512 瓦片。
- 只有画过的瓦片才分配内存。
- 线稿、网点这类稀疏内容会省很多。
- 合成器按脏瓦片重绘，不再每次重画整页。
- 导出时再拼成整页。

这是漫画能不能长期用的分水岭，不是优化项。

#### B. 撤销不能整页深拷贝

Strata 现在是整份文档快照，预算 640MB。漫画一张 20 层页面一步就可能超过预算，撤销会变成“只能撤一步”。

漫画撤销改成：

- 笔画级命令：记录笔迹参数、受影响瓦片的前后差异。
- 图层属性/格/气泡操作用结构化命令。
- 只保存脏瓦片差异，不复制整页。
- 目标：300dpi、20 层页面至少 50 步可撤销，内存不超过 1.5GB。

#### C. 分格裁剪要进合成器

不是画完再拿 PNG 去裁。每个格是形状 + 变换 + 裁剪蒙版；合成时：

1. 页背景。
2. 页级不裁层。
3. 各格组按格形状裁剪合成。
4. 跨格层按多格并集裁剪。
5. 气泡/文字在最上层。
6. 格边框单独一层。

这样拖动格、改边框、改 gutter 都是非破坏的。

### 5.4 笔刷能力继承清单

Strata 已有、漫画直接可用：

- 笔压映射大小/浓度，倾斜映射笔尖圆度/旋转，笔杆旋转，翻笔橡皮。
- 笔尖：圆、铅笔、粉笔、鬃毛、喷枪。
- 纹理：纸、画布、颗粒、斑点。
- 散布、数量、双轴散布、大小/角度/圆度抖动、颜色抖动、透明度/流量抖动。
- 硬度、流量、间距、平滑、拉绳、抬笔追笔。
- 对称：垂直、水平、双向。
- 湿边/混色？按 Strata 现有能力接入，不另造。

## 6. 工具清单

### 6.1 画笔

漫画专用预设，不是让用户从 40 个参数自己调：

- G 笔、映射笔、丸笔、学生笔。
- 圆笔、铅笔、干笔、墨染、马克笔、蜡笔、粉笔。
- 排线笔、交叉排线、点画笔。
- 速度线笔、集中线笔、闪电笔、云纹笔、花叶笔、砖墙笔。
- 网点笔、网点填充、渐变网点。
- 橡皮：硬边、软边、像素橡皮、蒙版擦除。

每支笔保留完整参数面板，但默认只显示“大小、浓度、硬度、纹理、压感”五个常用项，进阶项折叠。

### 6.2 图层与蒙版

- 像素层、文本层、网点层、纯色层、渐变层、组、调整层（基础）。
- 图层蒙版、剪贴蒙版、锁定透明像素、锁定位置。
- 混合模式沿用 Strata。
- 图层颜色标签：线稿蓝、草稿灰、网点紫、上色橙、参考绿。
- 格内图层和跨格图层在图层图标上区分。
- “参考层”：可见但不导出，专门放三视图和透视参考。

### 6.3 选区与变换

- 矩形、椭圆、套索、多边形套索、魔棒。
- 按格选择、按格内容选择、全页选择。
- 反选、扩展/收缩、羽化。
- 自由变换：移动、缩放、旋转、翻转、斜切；先做仿射，透视变形放第二阶段。
- 选区可以转蒙版，蒙版可以转选区。

### 6.4 文字与艺术字

- 横排、竖排；中文标点避头尾；自动换行。
- 字体、字号、字重、斜体、行高、字距、对齐。
- 描边、双描边、阴影、发光、渐变填充、图案填充。
- 弯曲：拱形、凸起、旗帜、鱼形、上升、挤压。
- 艺术字预设：标题字、拟声字、震屏字、手写旁白、印章字。
- 字体缺失警告；PDF 导出做字体子集化。
- 只允许可商用字体进入内置字体库，第三方字体显示授权来源。

### 6.5 气泡（Balloon）

气泡类型：

- 对话泡、思考泡、呐喊泡、耳语泡、旁白框、标题框、拟声字框。
- 形状：椭圆、圆角矩形、云朵、锯齿、爆炸、尖刺、虚线、手绘不规则形。
- 尾巴：贝塞尔曲线、双段控制、可拖拽锚点、可断开、可指向格内任意点。
- 文字：自动内缩、自动换行、溢出警告；竖排可用。
- 气泡跟随：默认跟随所在格移动；也可钉在页面上不跟格。
- 说话人：可选绑定 Lore 角色，导出/预览时可显示说话人标签，默认隐藏。
- 气泡层级：在文字层之上，避免文字被边框压住。
- 批量：复制气泡保留样式；统一改字体/描边/内边距。

#### 6.5.1 气泡的交互必须像“贴纸”，不像表单

1. **放气泡**：选气泡工具，在页面上按住拖出一个气泡；拖的时候实时改变宽高，松手即创建。
2. **拉大缩小**：选中气泡后八个手柄直接拖；不弹窗、不输入宽高。按住 `Shift` 等比，`Alt` 以中心缩放。
3. **拖尾巴**：尾巴根部/尖端各有一个控制点，拖尖端指向说话人；尾巴自动避让文字，不穿过气泡正文。
4. **双击打字**：双击气泡内部进入文字编辑，出现光标；直接输入，自动内缩、自动换行、溢出时边框变警示色。
5. **双击已有字**：全选当前文字，方便整体替换；`Esc` 退出，`Ctrl+Enter` 确认。
6. **在气泡上面画字**：切到“手写/艺术字”层，直接在气泡范围内写。笔迹可以设为“绑定气泡”：
   - 跟随气泡移动、缩放、旋转；
   - 默认被气泡形状裁切，避免写到气泡外；
   - 可关掉裁切，做“字冲出气泡”的拟声效果。
7. **不挡脸**：气泡拖动时显示“是否压住角色面部/眼睛”的轻提示，不强制阻止，只提醒。
8. **手机端**：单指点选，拖动移动，双指缩放；双击进入打字；键盘弹出时画布自动上移，不让输入框被键盘挡住。

#### 6.5.2 气泡与文字的数据关系

- 气泡是矢量容器，文字是独立可编辑对象，笔迹是独立艺术字层；三者不是一张扁平图。
- 气泡移动时，文字和绑定笔迹一起移动；解除绑定后各自独立。
- 导出 PDF 时文字尽量保留矢量；导出 PNG/PSD 时按图层栅格化。
- 气泡文字进入搜索索引（可选），方便找台词；不进入小说字数统计。

### 6.6 尺规与辅助

- 透视尺：一点/两点透视、消失点、地平线。
- 平行尺、曲线尺、椭圆尺、圆尺。
- 集中线：指定消失点，自动生成速度线/集中线。
- 对称尺：垂直/水平/双向。
- 网格、出血框、安全框、页面中心线、三分线。
- 吸附：格边框、页面中心、网格、尺规、其他格。

### 6.7 漫画专用网点

- 点网点、线网点、交叉网点、砂目、云纹。
- 参数：密度、角度、点大小、随机度、软硬。
- 可作用在选区、当前格、整页。
- 网点层保持可编辑参数，不直接栅格化。
- 300/600dpi 导出做莫尔纹检查；预览和导出分辨率不同要提示。

### 6.8 外部图片导入：直接放进线框里

漫画工作台必须支持从外部导入图片，不只是角色三视图。

**入口**

- 从电脑拖文件到画布/格上。
- 文件选择器：PNG、JPEG、WebP、TIFF、PSD（第一版先读 PNG/JPEG/WebP）。
- 剪贴板粘贴：截图、参考图直接 `Ctrl+V`。
- 手机相册/相机：选图或拍照，直接放进当前格。
- 从本书素材库/角色卡拖入。

**落点**

- 拖到某个格内部：图片自动成为该格的图像层，**默认被格形状裁切**，看起来就是“放进线框里”。
- 拖到空白页：成为页级图像层，不被格裁切，适合无框大场景。
- 拖到格边缘：显示“放入此格 / 放到页面”两个落点，不让用户猜。
- 多选格时导入：默认放进当前激活格；提供“铺满所有选中格”选项（谨慎，容易重复）。

**放置方式**

- 适应（fit）：完整显示，不裁切，可能留白。
- 填满（fill）：铺满格，超出部分裁掉，可拖图片调整构图。
- 拉伸（stretch）：非等比铺满，默认不推荐，需提示会变形。
- 平铺（tile）：用于纹理/背景，第一版可后置。

**编辑**

- 导入后是独立图像层：可移动、缩放、旋转、裁剪、调亮度/对比度、去色、半调网点化。
- 可设为“参考层”（不导出）或“素材层”（可描线、可上色）。
- 描线模式：图片降低不透明度并锁定，用户在上面新建线稿层。
- 外部图片的原始比例、版权/来源备注保留在图层元数据里。

**性能与格式**

- 大图导入时先降采样做预览，保留原图；导出用原图。
- 手机 HEIC 自动转 JPEG/PNG；带 EXIF 旋转要正确应用。
- 单页图片总内存超限时提示“降低预览分辨率/转黑白”，不直接崩。
- 图片进入同步清单：原图同步，缩略图不同步；冲突按页级哈希处理。

**手机端**

- 相册选图 → 预览 → 选择“放进当前格/整页” → 双指调整位置缩放 → 完成。
- 拍参考图时可以直接用后置摄像头，拍完自动放进当前格作为参考层。
- 手机屏幕小，导入后默认进入“图片调整”状态，不直接跳回画笔。

### 6.9 手机端绘画：不是电脑版的缩水版

用户明确说手机端画画会比电脑端更顺手。设计上把手机/平板当成**第一等绘画设备**，不是只读预览。

**默认形态：手机永远竖屏**

- 手机端**锁定竖屏**，不做横屏布局，不跟随系统旋转重排。
- 原因不是技术限制，是使用姿势：一只手拿手机，另一只手在屏幕上画/点；横屏需要双手端平，左右两侧像游戏摇杆一样操作，那不是画画，是打游戏。
- 竖屏布局：上方页面缩略图/话切换，中间当前页，底部大工具 Dock；默认进入“单格聚焦”，因为整页在手机上太小。
- 工具 Dock 放底部拇指区，高频工具在右侧，左手只负责拿稳手机；不把工具分到左右两边。
- 手机横过来时，只给一个轻提示“请竖屏使用”，画面不旋转、不重排，避免画到一半布局跳变。
- 平板默认竖屏两栏：左栏页/格，右栏图层/属性；不做三栏，不把桌面布局硬塞进来。

**笔与手势**

- 支持 Apple Pencil / S Pen / 第三方压感笔的压感、倾斜、方位、橡皮反手。
- 手掌防误触：落笔后短时间忽略手掌/手指触摸；手指仍可双指缩放/平移。
- 低延迟：笔迹预测 + 局部重绘；120Hz 设备按 120Hz 刷新。
- 双指平移/缩放；双指轻点撤销（可关）；三指重做（可关）；长按取色。
- 左手模式：工具 Dock 可左右翻转； palms 误触区域可调。
- 触感反馈：选中格、吸附、气泡对齐给轻震动；画画本身不震动。

**手机上的分格与气泡**

- 单指点选格，双击进格聚焦；多选用“选择模式”点选，不要求框选。
- 气泡：单指拖出，双指缩放，双击打字；键盘弹出时画布上移。
- 工具栏只放高频工具：画笔、橡皮、图层、撤销、选区、气泡、文字、更多；低频收进“更多”。
- 所有桌面右键/悬停功能都有长按替代。

**性能边界**

- 手机默认只渲染当前页 + 相邻页缩略图；其他页卸载。
- 大尺寸页用瓦片；单格聚焦只渲染该格和越界区。
- 导出/同步放后台，不阻塞画画；手机发热/低电时提示并降级动效。

## 7. 角色三视图与立绘库

### 7.1 角色卡

角色卡仍然属于单本书的 `lore.json`，不做全局 OC 档案。只有把几本书编进同一书组时，才允许把“书名、简介、角色三视图”这类最少数据设为组内共享；共享是可选开关，不是默认迁移。

- 正面、侧面、背面三视图。
- 表情：默认、笑、哭、怒、惊、羞、困、黑脸等。
- 手部/脚部/全身姿势参考。
- 配色板：主色、发色、瞳色、服装色。
- 身高比例尺、头身比。
- 服装变体：日常、校服、战斗服、睡衣。
- 备注：伤疤、饰品、不能画反的细节。
- 组内共享时，只共享只读三视图和最小角色卡；关系的深度、时间线、声音不进入书组。

### 7.2 画画时怎么用

- 右栏常驻“角色参考”面板：点名字就显示三视图，可并排、可叠在图旁边。
- 插入到当前格：作为 **参考层**（不导出）或 **素材层**（可描线、可上色）。
- 锁定比例：拖动时保持头身比。
- 描图模式：参考图半透明、锁定、只能在上面新建线稿层。
- 同一角色不同格可以共享同一套配色，减少画错颜色。
- 立绘只是 2D 图片/图层，不是 3D 模型；不做自动转面。

### 7.3 素材存放

- 角色图默认存本书 `comic/characters/<characterId>/`，不塞进 `lore.json` 的 base64。
- 如果角色被设为书组共享，原图和缩略图放到书组共享目录 `series/<seriesId>/shared/characters/<characterId>/`，组内其他书只读引用。
- 原图、缩略图分开；缩略图不进同步包。
- 支持 PNG/WebP；透明背景。
- 素材有来源/授权备注字段，避免以后商用踩版权。

## 8. 页面、话与阅读顺序

### 8.1 页面

- 单页、双页跨页、条漫长页。
- 页尺寸、出血、安全框、DPI、色彩模式。
- 页码位置：外侧/居中/隐藏。
- 页面背景：白/黑/透明/自定义。
- 跨页：两页共用一张画布，导出时按跨页切或整张输出。

### 8.2 阅读顺序

- 左→右 / 右→左。
- 格序号、气泡顺序、翻页方向统一由页面设置控制。
- 条漫：纵向连续滚动，格与格之间可设留白；导出成长图或分页 PDF。
- 预览模式能按阅读顺序逐格高亮，检查读者会不会看反。

### 8.3 话与页的关系

- 一话可以只有 1 页（短篇/条漫），也可以 50 页。
- 新建话自动建第一页，也可只建空话写脚本。
- 删除页要确认；页进入回收站/版本，不直接从磁盘抹掉。

### 8.4 手机端页面与话的适配

- 手机默认不显示整页三栏，而是“话 → 页 → 格”三级抽屉：
  - 第一层：话列表；
  - 第二层：页缩略图横向滑动；
  - 第三层：当前页/当前格。
- 页缩略图在手机上横向滑动，不堆成两列小图；每张缩略图下方只显示页码和状态点。
- 双击页缩略图进入该页；双击格进入格内聚焦；单击只选中。
- 阅读预览只做竖屏单页；跨页在竖屏里左右滑动/缩放查看，不自动切横屏双页。
- 条漫纵向连续滚动。
- 新建页/复制页/删除页放在“更多”里，避免误触。
- 手机上的“导出”默认只提供 PNG/PDF 预览和分享；PSD/CBZ 完整导出建议回电脑，但不禁用。

### 8.5 新建书视觉在手机端的适配

- 类型选择卡上下排列，书保持摊开形态，横线/线框等比缩放。
- 选中后底部出现固定“继续”栏，适配安全区；不把按钮压在书页上。
- 漫画设置项在手机上用底部抽屉分两步：先选形态/尺寸，再选色彩/模板；不一次塞 8 个下拉。
- 所有预览图（小说横线页、漫画分格页）在暗色/亮色主题下都能看清，不依赖单一底色。

## 9. 数据模型与磁盘结构

### 9.1 书级

`book.json` 增加：

```ts
kind: "novel" | "comic";
seriesId?: string;       // 可选：所属书组（同一世界观/系列）；为空表示独立书
comic?: {
  format: "page" | "webtoon" | "4koma";
```

### 9.4 磁盘目录

```
书名.chapter/
├─ book.json
├─ outline.json
├─ lore.json
├─ chapters/                  # 小说正文或漫画脚本
├─ assets/                    # 封面等通用素材
├─ comic/
│  ├─ project.json            # 漫画配置、页索引
│  ├─ pages/
│  │  └─ p_0001/
│  │     ├─ page.json         # 格、图层、气泡、文字
│  │     ├─ layers/           # 每层图片/瓦片
│  │     ├─ masks/
│  │     ├─ thumbs/
│  │     └─ page.webp         # 导出缓存，不参与同步
│  ├─ brushes/
│  ├─ tones/
│  └─ templates/
└─ sync-index.json            # 每个文件只留最新指纹
```

角色三视图、表情、服装参考默认仍在书内 `comic/characters/`；只有用户把角色设为“书组共享”时，才写到工作区级书组目录：

```
Chapter/
└─ series/
   └─ series_<id>/
      ├─ series.json            # 书组名、简介、成员书
      └─ shared/
         └─ characters/
            └─ ch_<id>/
               ├─ character.json
               └─ assets/
                  ├─ front.webp
                  ├─ side.webp
                  ├─ back.webp
                  └─ expressions/
```

原则：

- JSON 不塞 base64 大图；图层和角色图走独立文件。
- 未共享的角色只在本书里，不自动进书组。
- 书组共享的三视图只存一份，组内其他书引用 `seriesId + characterId`，不复制。
- 缩略图、预览缓存、临时合成结果不进同步。
- 页目录整体可独立读写，坏一页不拖垮整本。
- 资源用内容哈希命名，避免“复制页”后两份相同图重复占空间。

## 10. 手机互传要跟着扩展

现有互传白名单是小说文件。漫画必须扩，但不能把整本几 GB 全传。

### 10.1 新增同步白名单

作品包内：

- `comic/project.json`
- `comic/pages/**/page.json`
- `comic/pages/**/layers/*`
- `comic/pages/**/masks/*`
- `comic/brushes/**`、`comic/tones/**`、`comic/templates/**`
- `book.json` 的 `kind` / `comic` / `seriesId` 配置
- `chapters/*.md` 里的漫画脚本

书组层，只在书被关联到书组时携带：

- `series/<seriesId>/series.json`（书名、简介、成员书）
- `series/<seriesId>/shared/characters/**`（只带本书引用到的共享角色三视图，不是整个书组素材）

排除：

- `series/**/thumbs/*`
- `comic/pages/**/thumbs/*`
- `comic/pages/**/page.webp`
- `sync-index.json`
- 临时文件、`.deleted`、崩溃恢复文件
- 窗口、主题、语言、面板宽度等界面设置

### 10.2 差量单位

- 以“页”为单位比较：`page.json + layers + masks` 聚合哈希。
- 素材单独比较：同一张角色图没改就不传。
- 页的 `revision` 变化或聚合哈希变化才算改。
- 手机端没有漫画书时，电脑整本传，和现在小说逻辑一致。
- 手机端有书时，只传 `changedPages` 和新增素材。

### 10.3 冲突与删除

现互传的缺口，漫画必须先补：

- 同一页两边都改：不要静默覆盖；保留一份 `p_0001.conflict-手机.chapter`，让用户选。
- 删除页：加 tombstone（`.deleted` 或页索引里的删除标记），否则手机上的旧页永远删不掉。
- 目标端独有的旧页：按 tombstone 删除；没有 tombstone 就不删，只提示。
- 传输前先 flush 当前页未保存内容，避免传出去的是上一版。
- 传输中禁止切页、禁止退出；真实字节进度、真实速率，沿用现有互传的 `speed_bps` 采样。
- `.chapterpack` 里增加 `comic-plan.json`：页列表、页字节、素材列表、方向、冲突。

### 10.4 手机端未来

- 手机端第一章只做“接收/查看/导入”，不做完整画板；小屏画漫画体验差。
- 手机可以改气泡文字、台词、页顺序，这些是低风险编辑；复杂笔刷仍回电脑。
- 手机生成的包必须和电脑同一套 `comic` 结构，不能另造格式。

## 11. 导出

第一版必须支持：

- **单页 PNG/WebP**：含/不含出血，300/600dpi。
- **多页 PDF**：按阅读顺序，页尺寸准确，字体嵌入/子集化。
- **分层 PSD**：图层名、组、蒙版、文字层尽量保留；不能保留的明确降级为像素。
- **CBZ**：漫画阅读器通用。
- **EPUB3 固定版式**：可选，用于手机阅读。
- **整话长图**：条漫导出。

导出选项：

- 页范围：当前页 / 选中页 / 整话 / 整本。
- 出血：无 / 3mm / 5mm。
- 裁切 marks：开/关。
- 色彩：黑白二值 / 灰阶 / 彩色；黑白阈值可调。
- 网点：按目标 DPI 重算，避免缩放后糊成灰。
- 水印/页码：开/关。
- 文件名规则：书名_第X话_第Y页。

验收时必须用真实 300dpi、20 层、含网点、含竖排气泡的页面导出，不是空白测试页。

## 12. MCP 与外部自动化

Chapter 已有本机 MCP。漫画新增工具建议：

| 工具 | 作用 | 是否需要确认 |
|---|---|---|
| `comic_get_book` | 读书类型、页数、话数、页面尺寸 | 否 |
| `comic_list_pages` | 列页、缩略图路径、revision | 否 |
| `comic_create_book` | 新建漫画书 | 是（创建文件） |
| `comic_create_page` | 新建页，可套模板 | 是 |
| `comic_add_frame` | 加一个格，指定形状/位置/边框 | 是 |
| `comic_apply_template` | 给页套分格模板 | 是（覆盖当前页） |
| `comic_import_image` | 把外部图片放进指定格/页 | 是（写素材） |
| `comic_add_balloon` | 加气泡、文字 | 是（写页） |
| `comic_update_balloon` | 改文字/位置 | 是 |
| `comic_insert_character` | 插入角色参考/素材层 | 是 |
| `comic_export` | 导出 PNG/PDF/PSD/CBZ | 是（写文件） |
| `comic_delete_page` | 删除页 | 是 + 二次确认 |

原则：

- 书组关联的 MCP 工具见 20.7，不重复列。
- 读操作自由；写操作返回 diff 摘要。
- 删除、覆盖整页、批量替换必须用户确认。
- MCP 不直接操作画布内存，只操作磁盘上的页文件和结构化 JSON；正在编辑的页要先保存/锁定。
- MCP 生成的页/气泡要能在 UI 里正常撤销和继续编辑，不能变成不可读的二进制黑盒。

## 13. 性能、内存与可靠性

### 13.1 硬指标

| 项目 | 目标 |
|---|---|
| 300dpi A4 页面，20 个栅格层 | 可正常打开、绘制、导出 |
| 600dpi 单页 | 可打开；默认提示内存占用 |
| 画笔输入到显示 | 常规笔刷 < 16ms 一帧；大笔刷允许 30ms |
| 页面切换 | 1 亿像素以内 < 1.5s（缓存命中） |
| 撤销 | 50 步；不复制整页 |
| 自动保存 | 增量保存，单次 < 2s；不阻塞画笔 |
| 崩溃恢复 | 重启后能恢复最后一页最近 10 分钟内容 |
| 内存 | 单页编辑峰值 < 1.5GB；超过给明确提示 |

### 13.2 可靠性

- 每页独立保存；坏页不拖垮整本。
- 保存前写临时文件，成功后原子替换。
- 自动保存与手动保存不互相覆盖。
- 页删除进回收站/版本，不直接物理删除。
- 导出失败不破坏工程文件。
- 同步前 flush；同步中禁止改当前页。
- 断电/崩溃后，打开书时提示“有未完成恢复”。

### 13.3 兼容

- Windows 10/11 WebView2；Linux WebKit？
- 数位板：Windows Ink 优先；Wacom/Huion 压感、倾斜、翻笔橡皮。
- 触控板/鼠标：无压感时按 0.5，不假装有压感。
- 高 DPI 屏：画布坐标、笔刷大小、导出尺寸三者不能错位。
- 53 种界面语言下，工具栏不能挤爆；RTL 语言下画布阅读方向不受 UI 方向影响。

## 14. 你没提到、但漫画必须有的一批东西

下面这些不是可选项，是完整漫画工具链容易漏掉的：

1. **阅读顺序与格序号**：没有它，读者会把格子看反；日漫右→左、国漫左→右都要支持。
2. **出血、裁切、安全框**：印刷/导出必须；对话框压到裁切边会废页。
3. **跨页**：大场面需要双页一张画布，导出要正确切分。
4. **页码、话扉页、标题页**：单页文件不能替代成书结构。
5. **台词脚本与分镜的对应**：Chapter 是写作软件，漫画不能只剩画；每话要有脚本区。
6. **气泡自动避让/溢出警告**：文字超出气泡、压到格线、压到人物脸，都要提示。
7. **竖排中文标点**：逗号、省略号、引号、破折号在竖排里不能横着躺。
8. **字体授权与缺字**：内置字体必须可商用；缺字要当场提示，不能导出方框。
9. **网点缩放/莫尔纹**：预览 100% 和导出 300/600dpi 的网点密度要一致。
10. **黑色印刷控制**：黑白漫画的线稿不能是四色叠出来的糊黑；导出要有 K 通道策略。
11. **参考层/描图层的导出排除**：三视图、透视参考不能混进成品。
12. **素材版权备注**：角色图、网点、笔刷、字体都要能记录来源。
13. **页的复制/插入/排序/删除 tombstone**：否则同步后页序会乱。
14. **自动保存与崩溃恢复**：画一半崩了，不能整页没了。
15. **图层颜色标签/锁定/隐藏**：线稿、草稿、网点、上色必须能一眼分开。
16. **快捷键与数位板快捷键**：画画时手不能离开笔去点菜单。
17. **导出分层 PSD/CBZ**：只给 PNG 的漫画工具，实际交付会被卡住。
18. **大文件性能**：百万字小说可以存文本，漫画是几百 MB 图片，必须瓦片化和懒加载。
19. **页级同步冲突**：不能整本覆盖，也不能静默丢一边的修改。
20. **MCP 写操作审计**：AI 改页/删页必须可追溯、可确认。
21. **无障碍/键盘操作**：至少所有菜单和主要工具能键盘到达。
22. **素材搜索**：角色、姿势、网点、模板多了以后，没有搜索就是灾难。
23. **画布旋转/镜像检查**：画歪了要能转画布检查，导出不受影响。
24. **参考图透视网格**：贴图/场景参考需要透视网格，不只是三视图。
25. **文字/气泡的批量替换**：同一角色字体、描边、气泡样式要能统一改。
26. **页模板的“可编辑性”**：模板不能是死图，套完必须能拆格、拖格、改 gutter。

### 14.1 第二轮补充：按用户真实操作流必须有的东西

27. **新建书的类型视觉**：小说是摊开的横线书页，漫画是摊开的线框+淡线稿书页；不能只给两个文字按钮。
28. **类型卡的手机适配**：手机上上下排列、书等比缩放、底部“继续”，不把两张卡挤成邮票。
29. **铺格的第一入口**：空白页要先引导“拖模板/拖空框”，不能丢给用户一张白纸自己猜。
30. **模板拖放**：模板从抽屉拖到页面落点；拖入时预览格数和位置，松手可编辑。
31. **双击进格**：双击单格进入单格聚焦，只留这一格放大；双击多选格进入并集聚焦。
32. **退出聚焦**：`Esc`/返回整页，保留页、格、笔刷、缩放位置；不重置视图。
33. **超出格开关**：默认裁到格内，可开“超出格”保留越界笔迹，用于冲出格的人物/武器。
34. **无框画法**：支持空白页、无边框格、页级图层，做“没有格子”的整张场景。
35. **框选多格的真正目的**：不是批量改属性，是“一起画一张跨格的大画”；必须有“一起画”按钮。
36. **外部图片放进格**：拖文件/粘贴/相册选图，默认被格裁切；可选适应/填满/拉伸，能调整构图。
37. **外部图片的来源与版权**：图层元数据记录来源、授权、原图尺寸；商用风险要能追溯。
38. **气泡是贴纸不是表单**：拖出、拉大缩小、拖尾巴都是直接操作；双击就地打字，不弹属性窗。
39. **气泡上画字**：手写/艺术字层可绑定气泡，跟随移动缩放；可裁切也可冲出气泡。
40. **手机端是绘画端**：不是只读；单格聚焦、压感笔、防误触、双指缩放、长按取色都要有。
41. **手机端新建书视觉**：类型卡、设置抽屉、预览图全部按竖屏适配，不是桌面版缩小，也不做横屏布局。
42. **触控与鼠标等价**：右键/悬停/双击在手机上都要有长按/双击/选择模式替代。
43. **空状态与首次引导**：第一页给“铺格/套模板/导入图片”三个入口，不做一次性大教程。
44. **自动保存与统一撤销**：格、笔迹、气泡、文字、导入图片共用撤销栈；退出聚焦不弹保存框。
45. **阅读预览检查**：逐格高亮、气泡压脸提示、文字溢出、跨格断线检查，导出前一键跑。
46. **性能降级**：手机只渲染当前页和相邻缩略图；低电/发热提示并关动效，不静默卡死。

### 14.2 i18n：从第一天留 key，最后再翻译

用户明确说 i18n 放最后，因为“翻译一下就行”。这句话只对“翻译动作”成立，不对“代码结构”成立；如果前面把中文写死，最后会变成全项目返工。

**从第一天必须做的**

- 所有新增 UI 文案走 i18n key，组件里不写中文字符串。
- key 按模块命名：`newbook.*`、`comic.frame.*`、`comic.balloon.*`、`comic.mobile.*`、`comic.export.*`。
- 插画、书页里的示例字不参与翻译；用占位字形或可替换图层。
- 动态文案用参数，不拼句子：`已选 {count} 格`，不要 `"已选 " + n + " 格"`。
- 数量、日期、文件大小走本地化格式化；中文“万/亿”和英文 K/M 分开处理。
- 快捷键文案跟平台走：`Ctrl+Z` / `⌘Z`，不写死。
- 预留伪本地化测试：把中文替换成拉长 1.5 倍的假文，检查工具栏/气泡面板是否挤爆。

**最后才做的**

- 53 种语言的正式翻译、校对、术语统一。
- 漫画术语表：panel / frame、gutter、balloon、screentone、webtoon、4-koma、focus mode、spread。
- 翻译后跑一遍真实页面：类型卡、分格抽屉、气泡编辑、手机 Dock、导出对话框。
- RTL 语言只影响 UI 方向，不改变漫画阅读方向；漫画阅读方向由页面设置单独控制。
- 字体回退：UI 字体和漫画正文字体分开；缺字回退不能把气泡撑破。

**实施顺序**

- 功能开发阶段只做 key 和伪本地化，不追 53 语言。
- 所有功能稳定、文案不再改之后，最后集中翻译；翻译完只做回归，不再改结构。

## 17. 需要拍板的几个问题

这些会直接改数据模型或工作量，开工前要定：

1. **漫画层级**：按本文“卷 → 话 → 页”，还是你心里另有“卷 → 页”的扁平结构？
2. **默认页面**：B5 300dpi 黑白、左→右，是否符合你的主要用户？还是默认 A4？
3. **条漫**：第一版就做纵向连续流，还是页漫优先、条漫第二阶段？
4. **PSD/CBZ**：分层 PSD 和 CBZ 哪个先做？两个都做工作量不小。
5. **角色三视图来源**：只支持上传现成图，还是以后要内置人偶/3D 摆姿势导出三视图？
6. **小说书要不要单幅插图板**：本文默认不要；如果要，是另一个轻量功能，不混进漫画页。
7. **手机朝向**：已定，手机与平板都锁竖屏，不做横屏，不提供“手动开启横屏”的口子；只剩平板竖屏下用一栏还是两栏的布局问题。
8. **页面尺寸预设**：要不要内置日漫 B5、国漫 A4、条漫 1080×1920 等常用预设？
9. **类型卡视觉**：用统一的矢量书插画，还是允许用户用自己的封面做两张卡的预览？
10. **书组共享边界**：只共享书名、简介、角色三视图，还是也允许共享角色小传/称呼？本文按最小集设计，先不共享长篇设定。
11. **书组入口**：书单顶部用筛选 chip，还是单独一个“书组”文件夹/分组视图？本文建议 chip + 书组详情页，不另做首页。
12. **共享角色改动**：组内改三视图是全局生效（需确认），还是每本书可以本地覆盖？本文按“全局生效 + 可另存本地副本”。
13. **书组规模**：一个书组最多几本？本文建议先不限制，但 UI 只显示前 12 本，更多折叠。

## 18. 主要风险

1. **Strata 引擎是整页画布 + 整页撤销**：直接搬会内存爆。瓦片表面和瓦片撤销是前置条件，不是后期优化。
2. **分格裁剪与图层坐标**：格移动、跨格并集、跨页，任何一个坐标算错都会出现“画到这里跑到那里”。
3. **字体与网点授权**：内置字体/网点/笔刷必须可商用；不然用户作品会有版权风险。
4. **黑白导出**：线稿黑、网点灰、K 通道，三者不对就会印出来发灰。
5. **素材爆炸**：角色三视图、每层图片、每页缓存，不做内容哈希和懒加载，书会变成几个 GB。
6. **互传冲突**：漫画页是二进制+JSON 混合，页级冲突比小说文本更难合并；必须保留冲突副本，不能静默覆盖。
7. **UI 复杂度**：漫画工具很多，不能把所有参数一次性摊在屏幕上；要按“常用/进阶”分层。
8. **需求蔓延**：漫画很容易滑向“完整版 Clip Studio”，第一版必须守住“页漫 + 分格 + 线稿/网点/气泡 + 三视图 + 导出/同步”的主线。
9. **书组范围蔓延**：书组很容易被做成 OC 平台/宇宙百科；第一版只做“几本书 + 共享三视图/简介”，不扩关系网、时间线、声音、公开主页。
10. **共享角色冲突**：同一角色被多本书共享，改三视图会影响所有书；必须确认，并允许“另存本地副本”，不能静默覆盖。
11. **同名误合并**：不同书里同名角色不一定是同一人；加入书组共享必须手动勾选，不能按名字自动合并。
12. **手机书组视图**：书组在手机上是筛选 chip + 书组详情，不是 OC 仪表盘；不能把桌面多栏塞进竖屏。

## 19. 和当前互传工作的关系

- 互传协议、二维码、绑定、方向确认、真实进度、`sync-index` 这些继续按现有小说链路收尾。
- 电脑→手机浏览器的“扫码/绑定/比较/确认/下载/完成”已跑通；手机→电脑、Android 原生导入还要等手机端 Chapter 客户端，不在漫画设计里假装已经完成。
- 漫画只做 **预留**：`sync.rs` 的白名单、manifest、`.chapterpack` 结构、tombstone 设计要能接纳 `comic/**`，但不在本轮实现漫画页传输。
- 等漫画工作台落地后，再把 `comic/**` 加进白名单，不需要重写整套互传。
- 电脑端和手机端要先打通；漫画是下一阶段的大功能，不能抢当前互传的验收时间。
- 手机端在漫画阶段是正式绘画端，不只是接收端；互传协议要能传页、图层、蒙版和外部图片，不能只传一张合成图。

## 20. 小范围补充：书组 / 同一世界观（不做 OC 平台）

### 20.1 结论

Chapter 还是书本平台：书是主对象，文字书和漫画书并列。名字不变，首页还是书单，写作台/漫画台不大改。

只加一层很小的“书组”能力：用户可以把几本书连起来，表示它们是同一个世界观、同一个系列或同人分支。不做 OC 平台，不做全局角色库，不做角色首页。

### 20.2 书组是什么

- 一个书组 = 2 本及以上的书，可以跨类型（文字书 + 漫画书）。
- 书组有：名字、一句话简介、封面（可选）、成员书列表。
- 书仍然独立存在：独立目录、独立章节、独立导出、独立互传；书组只是标签和共享层。
- 加入/退出书组不移动书目录，不改书内容。
- 一本书同一时间只属于一个书组，避免“多重世界观”把数据搞乱；需要多世界观就复制书或另建书组。
- 书组不是强制合并：组内每本书仍可以有自己的局部设定、不同时间点、不同角色状态。

### 20.3 UI：只在书单上加一层，不做新首页

- 书单顶部加筛选 chip：`全部 / 未分组 / 书组名…`；不新增“书组首页”。
- 多选几本书 → 右键/更多 → “加入书组 / 新建书组”。
- 书卡片右下角显示书组小标签；点标签直接筛选同组书。
- 书详情页显示“所属书组”，下面列同组其他书，点一下直接打开。
- 书组详情页：书组名、简介、成员书、共享角色列表；可从详情页“添加书 / 移出书”。
- 角色仍然在本书 `lore` 里编辑；角色卡上多一个开关“在书组内共享三视图/简介”。
- 不做全局 OC 首页、不做关系网、不做时间线、不做素材库、不做声音档案、不做公开主页。

### 20.4 共享范围：只共享最少数据

可以共享：

- 书组名、一句话简介、成员书列表。
- 角色的名字、别名、一句话定位。
- 角色三视图（正/侧/背）、表情缩略图。
- 角色的基础配色板（发色/瞳色/服装主色）。

不共享：

- 章节正文、大纲、剧本、漫画页。
- 完整人物小传、关系网、时间线、声音、配音样本。
- 每本书的局部剧透设定。
- 任何素材原图以外的版权/授权细节（保留在书内）。

规则：

- 共享是手动开关，默认关闭；不会自动把书内角色上传到书组。
- 组内共享角色是**只读引用**；要改三视图，必须回到“源书”修改，或在本书“另存本地副本”后改。
- 修改共享三视图会影响所有引用它的书，保存前给一次确认。
- “另存本地副本”后，本书不再跟随共享，避免一本改图把全组画风带偏。

### 20.5 数据模型与目录

工作区级只增加一个 `series/`，不建 `ocs/`：

```
Chapter/
└─ series/
   └─ series_<id>/
      ├─ series.json            # 名字、简介、成员书、共享角色索引
      └─ shared/
         └─ characters/
            └─ ch_<id>/
               ├─ character.json  # 名字、别名、简介、配色
               └─ assets/
                  ├─ front.webp
                  ├─ side.webp
                  ├─ back.webp
                  └─ expressions/
```

书级只加一个字段：

```ts
// book.json
seriesId?: string;   // 为空表示未分组
```

`series.json` 最小结构：

```ts
interface BookSeries {
  id: string;
  name: string;
  description?: string;
  cover?: string;
  bookIds: string[];
  sharedCharacters: string[];
  createdAt: number;
  updatedAt: number;
}
```

原则：

- 共享角色只存一份三视图，组内书引用 `seriesId + characterId`，不复制大图。
- 未共享角色仍留在本书 `comic/characters/`；进组不迁移。
- 退出书组只删 `seriesId` 和共享引用，不动本书角色和素材。
- 删除书组不删书；只解除关联，提示“书还在”。
- 同名角色不自动合并；共享角色由用户从本书角色里手动选。

### 20.6 实施与验收

实施跟着漫画 P1 一起做，不单独开大阶段：

- 书组字段、书单 chip、书组详情页。
- 多选书加入/移出书组。
- 角色“共享三视图”开关；组内只读引用。
- 互传携带 `series.json` 和本书引用到的共享角色，不传整个书组。

验收：

- [ ] 能把两本书（一本文字、一本漫画）建成同一个书组。
- [ ] 书单能按书组筛选；书卡片显示书组标签。
- [ ] 打开一本书能看到同组其他书，并能直接跳转。
- [ ] 能把本书一个角色的三视图设为组内共享，另一本书能看到。
- [ ] 组内共享角色是只读；改图必须回源书或另存本地副本。
- [ ] 退出书组后，本书角色、封面、章节、漫画页都不丢。
- [ ] 删除书组只解除关联，不删除任何书。
- [ ] 手机竖屏能用书组 chip 筛选、打开书组详情，不出现 OC 仪表盘或横屏布局。
- [ ] 互传只带本书引用到的共享角色，不传整个书组素材。

MCP 只加最小工具：

| 工具 | 作用 | 是否需要确认 |
|---|---|---|
| `series_list` / `series_get` | 列/读书组 | 否 |
| `series_create` / `series_update` | 新建/改书组名、简介 | 是 |
| `series_link_book` | 加入/移出书组 | 是 |
| `series_share_character` | 把本书角色设为组内共享 | 是 |

### 20.7 明确不做

- 不做 OC 平台、OC 首页、OC 档案、关系网、时间线、声音档案、素材库。
- 不做公开社区、作品广场、排行榜、付费市场。
- 不做自动同名合并，不自动把书内角色变成全局角色。
- 不做跨书剧情连续性检查；只共享三视图和简介，不做“第 10 章死了第 20 章又活了”的推理。
- 不做书组级互传整包；仍然按书传，书组只带最小引用。

### 20.8 和漫画的关系

- 漫画三视图默认来自本书 `lore`；只有被设为书组共享时，才从 `series/shared/characters/` 只读引用。
- 同组文字书里的角色设定，可以在画漫画时当参考，但不强制同步。
- 漫画页、分格、气泡、导出仍按本书走，不受书组影响。
- 一本书退出书组后，漫画页里已经引用的共享三视图保留为本地副本，不会突然变空白。

## 21. 总结：这次到底加什么

- Chapter 仍然是书本平台，名字不变，书是主对象。
- 新增漫画书类型：新建时选小说/漫画，漫画有分格、气泡、跨格绘制、三视图、网点、外部图片、竖屏手机绘画。
- 新增很小的书组：几本书可以标成同一世界观，共享书名、简介、角色三视图；不做 OC 平台。
- 手机始终竖屏，不做横屏；平板也锁竖屏，桌面端三栏不变。
- 所有新增文案从第一天留 i18n key，正式翻译最后做。
