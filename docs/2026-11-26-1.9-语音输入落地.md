## 1. 方案

### 1.1 桌面：本地 whisper.cpp

- npm：`tauri-plugin-stt-api@0.2.2`
- Rust：`src-tauri/vendor/tauri-plugin-stt`
- 底层：`whisper.cpp`，按一下开始录音，再按一下停止，停止后整段转写。
- 模型目录：`C:\Users\ASUS\AppData\Roaming\studio.xiaofang.chapter\whisper-models`
- 下载镜像：`https://hf-mirror.com/ggerganov/whisper.cpp/resolve/main/`
- 三档模型：小号 75 MB、标准 142 MB、高精度 466 MB。
- 简体偏置：`src-tauri/vendor/tauri-plugin-stt/src/desktop.rs` 对 `zh` 设置
  `initial_prompt = "以下是普通话听写，请全部使用简体中文，并加上常用标点。"`
- 录音与转写都在本机，正文不出电脑。

### 1.2 Android：系统 SpeechRecognizer

- 使用插件自带 Kotlin `io.affex.stt.SttPlugin`，底层是系统语音服务，支持 `interimResults` 与 `continuous`。
- 权限：`RECORD_AUDIO` 由插件 manifest 带入；首次未授权时 `startListening()` 会弹系统授权框并立即 reject，界面提示“允许后再点一次麦克风”。
- 系统语言包和网络由手机语音服务决定；Chapter 不内置离线模型。

## 2. 手机端关键交互

### 2.1 语音启动先收键盘

- 收听态下正文 `contentEditable={!(isPhone && voiceActive)}`，正文不可编辑，不能获得输入焦点。
- `onPointerDown` 移动锚点后主动 `blur()` 当前焦点元素。
- 实测：键盘打开时点麦克风，键盘收起，正文 `contentEditable=false`，标点条出现，语音进入 `0:01`。

### 2.2 听写途中换落点

- 点正文用 `caretRangeFromPoint` / `caretPositionFromPoint` 取落点。
- 在落点插入 `span.voice-anchor[contenteditable=false]`，CSS 画 2px 闪烁竖线。
- 锚点与虚线预览 `.voice-ghost` 只存在于屏幕，保存前从 clone 删除，不写入正文存档。
- 实测：收听态点正文，锚点从 `x=18` 移到 `x=206`，键盘保持收起，语音保持收听。

### 2.3 连续落字与光标线

- `insertVoiceText()` 优先把文字并进光标所在的文本节点，或并入前一个文本节点，避免每次 final 都新开段落。
- 每次 final、标点、换行、退格后调用 `reanchorAt()` 重新插回光标线。
- `syncNow()` 保存前删除 `.voice-anchor` / `.voice-ghost`，并 `normalize()` 合并相邻文本节点。
- 实测：连续两次 final“甲乙”“丙丁”落在同一段；落字后光标线仍在；标点后仍在。
- 退格修复：光标线插在文末会留下空文本节点，退格会跳过光标线，删除前一个文本节点最后一个字；实测删掉句末逗号，光标线仍保留。

### 2.4 手机标点条

- 只在 `isPhone && voicePad && voiceActive` 时渲染；非收听态不占高度。
- 默认 8 键：`，。？！、…` + `↵` + `⌫`。
- 键高 44px；`flex: 1 1 44px; min-width: 44px; max-width: 96px`；条高 52px。
- 412 CSS 宽实测 8 键各 51px，左 0、右 412，铺满整行，没有右侧空白。
- 标点条在正文与格式坞之间的流内层，不覆盖正文、不覆盖工具栏。
- 设置里 `VOICE_MARKS` 共 12 个标点，可选 2–7 个，可恢复默认；`localStorage chapter.voicePad`、`chapter.voiceMarks` 持久化。

### 2.5 语音提示

- 手机收听态的提示胶囊改为流内元素，排在标签栏下方、正文上方。
- 实测 412 宽：提示高 33px，正文顶部从 249 下移到 288；不再压住“写作 / 大纲 / 设定 / 世界观”标签。
- 非收听态的错误提示仍用原浮层，结束后不会长期占正文高度。

## 4. 未验证 / 限制

- Android 模拟器没有外网：`ping 8.8.8.8` 100% 丢包；系统语音日志 `SodaSpeechRecognizer: Failed to get language pack ... error 12`；真实语音直接 `NETWORK_ERROR`。
- 因此 Android 真实 `partial` 替换、`final` 落字、`continuous` 重启没有在模拟器上完成；只验证了 JS 事件路径和 UI。
- 国产手机无 Google 服务、无离线语言包时，系统语音是否可用未验证。
- 桌面 whisper 是整段转写，不是流式；说话途中不能出字，只能停止后落字。
- 手机设置改 2–7 个标点是否即时作用到标点条未实测。
- 360 CSS 宽下 8/9 键是否横向滚动、44px 热区是否保持未实测。
- 语音只接小说 `Editor`，漫画气泡文本尚未接。
- Windows 安装包使用自签名证书，系统可能提示未知发布者；SHA256 见 `release/SHA256SUMS-1.9.0.txt`。
- Android arm64 包尚未在真机上安装验证。
