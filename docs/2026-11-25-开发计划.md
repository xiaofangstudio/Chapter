## 2. P0-1：多格并集聚焦 + 「跨格连画」

### 2.1 开关定名

- 中文界面名：**「跨格连画」**
- 英文/内部名：`Cross-panel draw`
- 代码名：`crossPanel`
- 数据名：`ComicJointLayer.crossPanel`
- gutter 统一叫「格缝」

按钮文案只写 **跨格连画**，副标题/提示写：
> 打开后，笔迹可以穿过所选格之间的格缝；格线仍显示在最上层。

不要叫“超出格”——现有的“超出格”是画出格边但仍在页面内，语义不同，别混。

### 2.2 用户操作链

1. 页模式：单击/Shift 单击/拖框选中 2 个及以上格。
2. 双击任意一个已选格，或点右侧“一起画”，进入 **多格并集聚焦**。
3. 聚焦顶栏显示 `2 格并集` / `3 格并集`，出现「跨格连画」开关。
4. 默认 **关**。
5. 关：笔迹只落在各格并集内，格缝没有墨。
6. 开：格缝也变成可画区域，笔迹连续穿过格缝。
7. 格线始终最后绘制，压在所有笔迹上面；笔迹从格线底下穿过去。
8. `Esc`/返回整页退出，保留当前页、工具、笔刷、缩放位置。

### 2.3 开关行为表

| 状态 | 可落笔区域 | 进入格缝 | 格线 | 退出后 |
|---|---|---|---|---|
| 跨格连画关 | 所有选中格形状的并集 | 否 | 最上层 | 每格仍可单独编辑 |
| 跨格连画开 | 并集 + 相邻选中格之间的格缝走廊 | 是 | 最上层 | 缝里的像素保留，关掉只是遮住 |

- 开关不是删除像素：关掉后缝里的笔迹**隐藏**，重新打开要恢复；保存重开也要保持。
- 默认不把像素复制到每个格；使用一张页级跨格层，避免同一笔在四格重复、后期改不动。

### 2.4 多格并集聚焦

- 视图范围：所有选中格的包围盒 + 24px 内边距，等比放进工作区。
- 未选中的格：隐藏内容，最多留 8% 轮廓，不允许误以为能画。
- 选中格按原相对位置显示，不能重新排成一行。
- 多格聚焦时显示每格淡淡的边界和编号，方便知道笔落到哪一格。
- 单格双击仍进入原来的单格聚焦，不破坏现有习惯。
- 多选状态下双击一个**未选中**的格：退出多选，进入该单格。

### 2.5 数据模型

在 `src/comic/types.ts` 增加：

```ts
export interface ComicJointLayer {
  id: string;                 // j_xxx，全页唯一
  name: string;               // 默认「跨格线稿」
  visible: boolean;
  opacity: number;
  locked?: boolean;
  blendMode?: ComicBlendMode;
  frameIds: string[];         // 创建时绑定的格；用于重建 mask
  rect: { x: number; y: number; w: number; h: number }; // 页坐标包围盒
  crossPanel: boolean;        // 跨格连画开关
  createdAt: number;
}
```

`ComicPage` 增加：

```ts
jointLayers?: ComicJointLayer[];
```

- 老页面没有 `jointLayers`，按空数组处理。
- 保存目录沿用 `comic/pages/<page>/layers/<jointId>.png`，不需要新目录。
- `page.json` 里保存 `jointLayers` 元数据。
- 加载页面时，把 joint 图层载入独立 map，key 用 `j:<id>`，不要和 `f:<frameId>:<layerId>` 冲突。

### 2.6 画布与掩膜算法

在 `src/comic/joint.ts` 新增 `buildJointMask(page, frames, crossPanel, maxGap=160)`：

1. 在所有选中格包围盒内建一张 mask canvas。
2. 每个格按 `rect`/`quad` 填充白色。
3. 每个格的路径向外膨胀 `maxGap/2 + 2`（Canvas `lineWidth = pad*2`），两侧合起来刚好覆盖 160px 以内的整条格缝，而不是只桥接缝中心。
4. `crossPanel=false`：不膨胀，只保留各格并集。
5. `crossPanel=true`：并集 + 膨胀覆盖格缝；再用 `jointGapBridged` 扫描所有格之外的像素，确认真的形成格缝桥。
6. 不对未选中的格桥接。
7. mask 只在进入聚焦、格移动、开关切换时重建；落笔时只做裁剪，不每帧重算。

### 2.7 绘制顺序（必须改 `drawPage`）

现在 `paintFrameContent` 每画完一格就立刻画该格边框，导致页级跨格层插不进去。改成四遍：

1. 页背景。
2. 所有格内容（不含边框）。
3. 所有 `jointLayers`（按 mask 裁切，按图层顺序与混合模式）。
4. 所有格边框。
5. 气泡 / 文字 / 图片（按原有层级）。

这样跨格笔迹在格内容之上、格线之下，符合“缝在图层顶上，笔从底下穿过去”。

### 2.8 进入多格后的落笔

- 进入多格聚焦时自动创建/选中一张 `跨格线稿`。
- 如果当前选中组已有对应 `jointLayer`（frameIds 完全一致且未删除），直接复用，不每次新建。
- 画笔、橡皮、填充、形状、移动、选区都作用于这张 joint canvas；选区遮罩要和 joint mask 相交。
- 图层栏显示 `跨格线稿 · 2格`，带一个小链接图标，和普通格图层区分。
- `跨格线稿` 支持可见、锁定、不透明度、混合模式；先不做剪贴蒙版。
- 关闭 `跨格连画` 时，落笔仍进同一张 joint canvas，但 mask 变回并集；缝里的旧像素隐藏。
- 再次打开，缝里的旧像素恢复显示。

### 2.9 撤销、保存、缩略图、导出

- 笔画级：`joint` 图层落笔前 clone 整张 joint canvas，落笔结束 push 一条 `joint` 撤销记录；先沿用现有整层快照，不急着做瓦片。
- 开关切换不进撤销栈，但写进 `page.json`，保存后保持。
- 保存：`savePage` 遍历 `page.jointLayers`，把 canvas 转 dataURL 一并写盘；加载时恢复。
- 缩略图：`makeThumb` 也必须画 jointLayers，否则保存后缩略图和实际页不一致。
- 导出：等漫画导出功能接入时复用同一套 `drawPage` 顺序，不另写一套合成。

### 2.10 验收

- [ ] 页模式框选 2 格，双击任意已选格，进入 2 格并集。
- [ ] 未选中的格不显示内容，选中格相对位置正确。
- [ ] 默认「跨格连画」关；跨缝画线，缝里无墨。
- [ ] 打开开关；同一位置画线，缝里有墨，线连续。
- [ ] 格线仍在线上面，不被笔迹盖住。
- [ ] 关掉开关，缝里的墨消失；再打开恢复。
- [ ] 保存、关闭、重开，开关状态和缝里的像素都在。
- [ ] 撤销一笔只撤这一笔；不影响格图层。
- [ ] 3 格 L 形布局，两条相邻格缝都能连。
- [ ] 两格距离 > 160px，不自动连接并给提示。
- [ ] 缩略图与整页显示一致。
- [ ] Android 单指点选 2 格 → 一起画 → 跨格开关可用；不要求拖框。

## 3. P0-2：Android 正式开发

### 3.1 技术路线

继续用 Tauri 2 + React 19 + 现有 Rust 命令，不另起原生 Android 项目。

- 包名沿用 `studio.xiaofang.chapter`。
- 首版 `minSdk 24`，`targetSdk 35`（本机已装 android-35）。
- 手机锁竖屏；平板也先竖屏两栏，不做横屏三栏。
- 主力 ABI：`arm64-v8a`；模拟器加 `x86_64`。
- Android 第一版不承诺：本机 MCP、Git 版本、复杂打印排版、桌面多窗口。

### 3.2 明天开工顺序

1. 版本号全项目改 `1.7.0`：
   - `package.json`、`package-lock.json`
   - `src-tauri/tauri.conf.json`
   - `src-tauri/Cargo.toml`
   - README 顶部
2. 安装 Rust 目标：
   ```powershell
   rustup target add aarch64-linux-android armv7-linux-androideabi i686-linux-android x86_64-linux-android
   ```
3. 初始化 Android 工程：
   ```powershell
   npx tauri android init
   ```
   生成 `src-tauri/gen/android`；把 `gen/android` 纳入必要时的手改，但不要把生成物乱改到无法再生成。
4. 平台路径适配（先做，避免后面所有文件功能在 Android 上全废）：
   - `src-tauri/src/lib.rs` 现在 `default_library()` 固定 `home/Documents/Chapter`，Android 不可用。
   - 桌面保持 `Documents/Chapter`；Android 用 `app.path().app_data_dir()/Chapter`。
   - `load_library` / `settings_path` / `open_book` 都要能接 `AppHandle` 或启动时注入根目录。
   - Android 首次启动自动创建 `Chapter` 目录和 `settings.json`。
   - Android 打开外部 `.chapter`：先用 SAF 复制到 app 私有目录再打开；不要直接拿 `content://` 去 `std::fs`。
   - Android 导出/分享：先写 app cache，再走 FileProvider/share intent；不要假设 `Documents` 可写。
5. Manifest：
   - `android:screenOrientation="portrait"`
   - `android:resizeableActivity="false"`（手机；平板若以后要两栏再放开）
   - 状态栏/导航栏配色贴合纸面，安全区用 `env(safe-area-inset-*)`
   - 应用名 `Chapter`，图标用现有 1024 图标生成 adaptive icon
6. 先跑通 debug：
   ```powershell
   npx tauri android dev
   ```
   模拟器 `emulator-5554` 已在跑；能安装、能启动、能读写一本测试书为第一步。
7. 再出包：
   ```powershell
   npx tauri android build
   ```
   产出 APK/AAB；先 debug 可安装，再做 release 签名。

### 3.3 Android 存储与文件边界

- 书库根：app 私有 `files/Chapter`，不要求用户给存储权限。
- “导入书/工程”：系统文件选择器 → 复制进私有书库；原文件不动。
- “导出/分享”：生成到 cache → 调系统分享/另存；不直接写公共目录。
- 自动保存：`visibilitychange` + Tauri 生命周期双保险；切后台前 flush 当前页/当前章。
- 返回键：按层级退（键盘 → bottom sheet → 聚焦 → 页面 → 书 → 书库），最后才退出 App。
- Android 第一版不接 Git/MCP；设置里隐藏或显示“桌面端可用”，不要点了报错。

#### 触控规则

- `pointerType === "pen"` 才走压感笔画；手掌/手指在笔落下的 500ms 内不落墨。
- 单指：当前工具；双指：平移/缩放；三指：重做（可关）；双指轻点：撤销（可关）。
- 所有 hover/右键功能补长按菜单。
- 选区/图形/移动在手机上必须能在“更多”里找到，不藏在桌面 hover 里。
- 工具栏不横向滚动到看不见；超过 6 个就进 sheet。
- 所有弹窗宽度不超过屏宽 - 32dp；按钮上下排列时不挤压。

#### Android 性能

- WebView canvas DPR 上限 2；不要 3x 全量渲染。
- 继续用脏矩形；Android 上禁用大面积 `backdrop-filter` 和高成本阴影。
- 只渲染当前页 + 相邻 1 页缩略图；其他页卸载。
- 画笔输入到显示目标 ≤ 1 帧（60Hz 约 16ms；120Hz 约 8ms），不允许 >50ms 长任务。
- 低端机自动关闭背景流光、3D 书、复杂入场动画。
