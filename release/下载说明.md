# Chapter 1.5.0 下载说明

## Windows x64

- `Chapter_1.5.0_Windows_x64_setup.exe`：安装版，双击安装。
- `Chapter_1.5.0_Windows_x64_portable.exe`：免安装版，直接运行。

## Linux / macOS（当前仍为 1.4.0）

- `Chapter_1.4.0_Linux_x64.deb`：Debian / Ubuntu 安装包。

  ```bash
  sudo apt install ./Chapter_1.4.0_Linux_x64.deb
  ```

- `Chapter_1.4.0_Linux_x64.AppImage`：通用免安装版。

  ```bash
  chmod +x Chapter_1.4.0_Linux_x64.AppImage
  ./Chapter_1.4.0_Linux_x64.AppImage
  ```

  PDF 导出需要系统中存在 Edge / Chrome / Chromium 之一。

## macOS

`Chapter_1.4.0_macOS_build-kit.zip` 是 macOS 构建包，不是现成 DMG。
Tauri 的 macOS 打包依赖 Apple SDK、`codesign` 与 `hdiutil`，必须在 macOS 上完成，
Windows / Linux 无法交叉产出可用的 `.dmg`。

在 macOS 14+ 解压后执行：

```bash
bash scripts/build-macos.sh
```

会生成通用架构（Intel + Apple Silicon）的 `.app` 与 `.dmg`，产物在：

```text
src-tauri/target/universal-apple-darwin/release/bundle/dmg/
```

仓库内的 `.github/workflows/build-desktop.yml` 也可以在 GitHub Actions 的
macOS runner 上一次产出 macOS 与 Linux 包。详细说明见 `docs/build-macos.md`。

## 右键与撤回

- 卷头右键：添加一章、重命名本卷、删除本卷。
- 章节卡片右键：打开这一章、添加一章、重命名、删除本章。
- 菜单支持方向键、Esc 关闭。
- 删除卷 / 删除章 / 重命名卷 / 重命名章 / 移动章节 / 移动卷 / 移动场景 / 新建卷
  都进入撤销栈，在非输入框位置按 `Ctrl+Z`（macOS 为 `Cmd+Z`）撤回。
- 撤销删章会优先把 `.md.deleted` 原文件改回 `.md`；若没有备份，则用内存中的正文补写。

## 本轮 1.5.0 更新（2026-11-24）

- 底部工具条统一为胶囊形；颜色入口改为圆形色环，去掉生硬的“+”。
- 20 套笔刷全部换成真实笔尖小样，不再用竖线占位。
- 新增对象 / 矩形 / 柳叶 / 魔棒四类选区；支持扩展、容差、连续区域、全选、反选、
  取消，Shift 加选、Alt 减选；画笔、橡皮、填充都按选区遮罩裁切。
- 颜色新增 SV 取色盘、色相条、HEX 输入、最近色与个人色板（右键移除）。
- 以上仅重打 Windows 包；Linux 与 macOS 仍为 1.4.0。

## 上一轮 Windows 包更新（1.4.0）

- 新建书可选文字书 / 漫画书；漫画书直接进入漫画工作台。
- 漫画分格不再只有横平竖直：模板分「连环画 / 漫画 / 整页」三组；连环画保留
  六格、四格、电影条、大场面、三连；漫画提供切角四格、斜切三格、放射五格、
  错位四格，弹窗缩略图按真实斜边绘制。
- 用户可以自己画格：工具栏「手绘格」或模板弹窗「手绘一格」，在页面上点四个角，
  前三步有橙色虚线预览，第四角落成四边形；四点自交或面积太小会被拒绝。
- 四边形有四个真实角点手柄，可逐角拖动改形；整格移动、格内落笔裁剪、气泡命中、
  保存重开都按新形状走。
- 套模板会同时清空格、气泡、图片；页面只有气泡或图片也会先确认。改角 / 缩放撤销
  会同步恢复旧画布，重做按新包围盒重铺图层；套模板撤销会恢复原格与原始笔迹。
- 最小书组：新建、改名、简介、分书/移出、解散、书架筛选，以及组内共享角色开关。
- 书架漫画卡片显示“漫画”而不是章/字数；书组筛选与卡片标签实时同步。
- 1.4.0 当时只重打了 Windows 包；Linux 与 macOS 包仍是更早的构建。
